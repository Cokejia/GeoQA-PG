# 第一篇土壤地理  

土壤地理学是地理学与土壤学之间的边缘科学，它是以土壤与地理环境之间的特殊矛盾为对象，研究土壤的发生、发展、分异和分布规律的科学。  

# 第一章土壤剖析  

# 第—节概述  

土壤是自然地理环境的一个重要组成成分，又是由自然地理环境的其他组成成分相互作用形成的特殊自然体。在自然界中，土壤圈（土被)处于大气圈、岩石圈、水圈和生物圈的接触过渡地带（图1-1），是有机界和无机界的结合部，是自然地理环境各组成成分的枢纽，是自然地理环境中物质循环和能量转化的重要环节和活跃场所。  

一般来说，土壤是指地球陆地表面具有一定肥力、能够生长植物的疏松层。它有自己的发生、发展过程，是一个从形态、物质组成、结构和功能上可以剖析的自然实体。

# 一、土壤剖面的发育  

地球陆地表面上的士壤是在不停地变化着的，基岩风化所产生的疏松碎屑，便是土壤发育的母质。暴露于大气中的残积母质或运积母质在适宜的条件下，便有可能着生绿色植物，植物的生长，将导致有机残体的积聚，继之，土壤动物、微生物也得以繁衍。有机残体的分解，释放出其所含的营养物质，供植物生长周期应用。当有机质在土壤表层聚积到一定程度时，便形成了具有一定厚度、呈暗黑色的有机质聚积层（A层），这时，赖以有机残屑为生的微生物和土壤动物也就成了整个有机质复合体的组成部分了。微细颗粒和可溶性物质等随渗漏水下移，往往会在某一深度处淀积下来，从而形成一个相对粘重、紧实的淀积层（B层）。A层和B层合称土体。土体的下部则过渡到轻微风化的地质沉积物或基岩，即为母质层(C层)或母岩层(R层)。土壤剖面就是指从地表向下直至母质的土壤纵切面。显然，它并非均一的，而是由一些形态上和性质上各不相同的土层组合而成。这些土壤层次大致呈水平状态，它们是在土壤发育过程中形成的，故称为土壤发生层，简称土层。  

在十九世纪末，俄国土壤学家道库恰耶夫把土壤剖面分成三个发生层:腐殖质累积层(A)过渡层(B)和母质层(C)。随后的研究者又提出许多新的命名建议，但基本上仍未脱离道库恰耶夫的A、B、C传统命名法。自然土壤剖面一般分为以下几个层次。  

枯枝落叶层：它是由聚积在地面上的枯枝落叶所构成，森林土壤常有这一层次，草原土壤此层不甚明显或没有。  

腐殖质层：它是在接近地表处所形成的矿质土层，以腐殖质积累为主要特征，而且腐殖质已和矿物质紧密相结合。该层颜色常较下面土层深暗。  

淋溶层：由于淋溶作用而使物质迁移或损失的土层，其中包括灰化层，灰化层是由于强烈的淋溶，不仅易溶物质淋失，而且难溶物质如铁、铝，以及粘粒等也发生下移，留下来的是最难移动、抗风化最强的矿物质如石英等。淋溶层颜色较浅，颗粒也较粗，砂粒和粉粒的含量较高。  

淀积层：上层淋溶下来的物质在本层淀积，质地粘重，具有柱状或棱柱状结构，较紧实，常呈棕色或红棕色。  

母质层：它乃是岩石风化物的残积物或运积物，基本未受到成土作用的影响。  

母岩层：它是未风化的岩石。

# 二、单个土体和聚合土体  

土壤剖面虽是研究土壤性状很有用的手段，但它只能代表该观测点的状况，而无法反映土层厚度的水平变化情况，也未能表示出间断的土层。因此，在土壤调查时，还必须在调查范围内确定一个能够足以代表某一种土壤大部分特性的标本单元，这个标本单元就叫做单个土体（Pedon）\*（图1-4）。单个土体是土壤剖面概念的立体化。它是一个三维空间体，其横截面大体上近似六角形。既然一种土壤在空间分布上，有的是连续的，有的是断续的，表现出一定的变异，因而单个土体的横截面大小也是可变化的。单个土体的最小面积为1平方米，而土层的横向上不连续时，则可延伸到10平方米。单个土体类似于一个晶体的“单位晶胞”，它又好比花布的基本设计一样，重复出现格局的主题。  

![](images/e88e6ba72c1d9195b99b65dd3e4f72ea36a1300525b35250cf2c41e7f6f46dcd.jpg)  
图1-4单个土体和聚合土体示意图  

土壤无论在空间上和时间上，都是呈连续状态存在的。我们可以根据一种或多种因素所造成的差异来划分成若干土壤单元，它是由一些相互毗邻、特性相同的单个土体所组成的群体，即所谓聚合土体（Polypedon），又叫做土壤个体（Soil individual）。聚合土体之间存在着层次排列、土壤特性等方面的差别。聚合土体相当于土壤系统分类中的基本单元，是从事土壤研究的重要对象。  

# 三、土壤肥力和土壤生产力  

土壤不仅是一个独立的历史自然体，同时也是一种重要的自然资源。作为资源，土壤具有一定的肥力和生产力。土壤肥力是指土壤为植物生长供应和协调营养因素(水分和养料)以及协调环境条件(温度和空气)的能力。一般将水、肥、气、热称为土壤肥力四大因素。土壤肥力乃是土壤物理、化学、生物等性质的综合反映。然而，土壤生产力则是指土壤在一定的管理系统下能生产某一定植物或植物系列的能力。土壤生产力是所有影响植物产量的全部因素(包括土壤的和非土壤的)之综合反映。  

肥力和生产力是两个不同的概念，彼此既有联系又有区别。肥力只是生产力的基础，而不是生产力的全部。实践表明，高产的土壤必定是肥沃的，但不能因此断定，肥沃的土壤一定高产。土壤生产力的高低，除了受肥力因素制约外，显然，还要考虑土壤所处的自然环境和社会经济条件，包括气候、日照状况、地形及其相关联的排水与供水条件、有无毒质或污染物质的侵入等等，也包括耕作、施肥、灌溉等等土壤管理措施。

# 一、土壤矿物质  

土壤矿物质主要是从成土母质继承和发展而来的，是土壤的重要组成部分之一，在大多数土壤中，其重量可占土壤固体物质总量的90%以上，常被称为土壤的“骨骼”。它对土壤的性质、结构和功能影响甚大，同时土壤矿物的组成也是土壤形成过程的重要标志。  

# （一）土壤的矿物组成  

土壤矿物按其成因类型，可分为原生矿物和次生矿物两大类。  

# 1．土壤原生矿物  

土壤原生矿物是各种岩石(特别是岩浆岩)受到程度不同的物理风化，而未经化学风化的碎屑物质，其原来的化学组成和结晶构造都没有大的改变。原生矿物主要分布于砂粒和粉粒中，有些极  

细的则可归入粗粘粒部分。  

土壤中主要的原生矿物有：硅酸盐和铝硅酸盐类的正长石、斜长石、白云母、黑云母、辉石、角闪石、橄榄石，氧化物类的石英，硫化物类的黄铁矿和磷酸盐类的磷灰石等。其中以石英、长石、白云母、黑云母、角闪石、辉石等最为常见。  

土壤中原生矿物的种类和含量，一方面随母岩和母质类型、风化强度和成土过程的不同而异，另一方面还与矿物本身的抗风化能力有关（表1-3）。  

表1-3土壤原生矿物的抗风化能力及其化学成分  

![](images/7940192c433975c23726186aee0896868bf2b838f3d5ed21505f84e5795e72ad.jpg)  

在原生矿物中，石英最难分解，长石次之，辉石、角闪石、黑云母易风化，因而石英常成为较粗的颗粒保留在土壤中，实际上它是土壤的基质；辉石、角闪石、黑云母等在土壤中很少残留，一般都转化为次生矿物。土壤原生矿物除构成土壤的大小颗粒外，而且还是土壤中各种化学元素的最初来源，其类型和数量关系到土壤的化学成分。  

# 2.土壤次生矿物  

土壤次生矿物大多数是由原生矿物经风化后重新形成的新矿物，其化学组成和构造都有所改变而不同于原来的原生矿物。次生矿物是原生矿物的改造产物，颗粒纤细，结晶较差，甚至是极细的非晶质颗粒。次生矿物主要分布于粘粒内，有些可作为粘粒薄膜包裹着粉粒和砂粒，使之着上各种颜色，并起着胶结剂的作用，把粗细颗粒互相粘结形成团聚体。  

十壤中次生矿物的颗粒很小，由其构成的溶液具有胶体性质。它既是土壤中粘粒和无机胶体的组成部分，又是土壤固体物质中最活跃的部分。其种类众多，根据土壤次生矿物的构造和性质大体上可归纳为三类：简单盐类、次生氧化物类和次生铝硅酸盐类。  

（1）简单盐类简单盐类包括各种碳酸盐、重碳酸盐、硫酸盐和氯化物等。常见于干旱、半十旱地区的土壤中。  

（2）次生氧化物在土壤次生矿物中，氧化物矿物在数量上虽远不如次生铝硅酸盐矿物，但其种类不少，在土壤性质上所发挥的作用不可轻视。此类矿物对成土环境和成土过程的变化颇为敏感，随时可以改变结晶状态，土壤中存在着结晶程度高低不等的一系列氧化物。非晶质氧化物比表面大，化学活性高，常与次生铝硅酸盐矿物或腐殖质结合，脱水后则转变为晶质矿物。在土壤剖面中，次生氧化物的分布很不均匀，既可散布在土粒上；也可集中形成条纹、斑点；或以单独的颗粒出现，其粒子小的要放大几万倍才能看清楚，大的可以达到相当大；它们还可把土粒胶结成为结核、硬磐等等。如铁、铝氧化物常在土粒表面形成胶膜，对土壤团聚体的形成起着胶结作用，同时在一定程度上也影响着士粒的表面性质，并使土壤呈现各种不同的颜色。  

次生氧化物主要有水化氧化物和三氧化物的水化物。  

水化氧化物中，最常见的是二氧化硅的水化物。它是由铝硅酸盐类矿物在化学风化中所产生的硅酸形成的。最初是以硅酸的分子溶液存在，而后变成溶胶和凝胶，凝胶进一步脱水，便逐渐变为细小的结晶颗粒—一次生石英。二氧化锰水化物的形成情况也与此相似。

高岭石组包括高岭石、埃洛石等粘土矿物。在土壤中以高岭石为最多，广泛分布于热带、亚热带的土壤中。高岭石是由一层硅氧片和一层水铝片迭合而成，属1：1型双层晶格的粘土矿物。其化学分子式为AI2Si2O（OH)或写成Al2O；·2SiO，·2H2O，硅铝比率(SiO2/Al2O3)为 2。这个1：1型矿物晶体单元的一面是氧原子，另一面是OH群，在相邻的两个晶体单元之间产生了氢键的关系，氢键的联系力强，使得晶层之间的距离固定不变，遇水不膨胀，因此不具有内表面，而称为非胀缩性粘土矿物。高岭矿物极少发生同晶替代，以至由此产生的负电荷极少，只是在一定酸性条件下，晶体表层OH群中H+的解离而带负电荷，故吸附阳离子的能力较弱。高岭石一般为边缘清晰的六角形，粒径多在0.2～2微米范围内。高岭石的吸水力、可塑性、粘着性均较弱。  

蒙脱石组包括蒙脱石、绿脱石、拜来石等粘土矿物，以蒙脱石为代表。这类矿物的晶体单元是在两层硅氧片之间夹着一层水铝片组合而成，属2：1型三层晶格的矿物。其化学分子式为Al2Si4Oo(OH)2·nH2O,或写成 Al2O·4SiO2·H2O+nH2O,硅铝比率一般等于4。2：1型矿物晶体单元的两面都是氧，故相邻晶层之间联系力弱，遇水易膨胀，而叫做胀缩性粘土矿物，具有巨大的内表面。2：1型矿物普遍有着同晶替代现象，使之带有负电荷，拥有较强吸附阳离子的能力。其粒径小于1微米，故分散度高，吸水性强，同时可塑性、粘结性和粘着性也都很强。它所吸收的水分，植物难以利用，所以富含蒙脱石的土壤，植物易感水分缺乏，且干裂现象严重，对植物生长不利。蛭石与蒙脱石同属2：1型胀缩性粘土矿物。不同之处仅是八面体中少数位置上的铝被镁所取代，少数蛭石，镁比铝占优势。性质与蒙脱石相类似。  

水化云母组·伊利石是这一组的主要代表。它也属于2：1型粘土矿物。其化学分子式是KAl2SiaO1o（OH)2·nH2O或可写成K+·Al2O·4SiO2·H2O+nH2O,与蒙脱石组基本相同。它们之间的差异在于水化云母的相邻晶层之间有K+的存在，由于K+的引力使晶层间结合较紧密，遇水时膨胀受到限制，故胀缩性较小。水化云母也有同晶替代现象，使之带有负电荷，其吸附阳离子的能力介于前两者之间。水云母吸附有K+，所以含水云母多的土壤，钾素养分十分丰富。此外，水化、可塑性、粘结性、粘着性以及分散的难易程度都比蒙脱石小,但高于高岭石。伊利石结晶颗粒的大小亦介于高岭石与蒙脱之间。

# 2．土壤结构  

土壤质地对土壤理化性质的影响很大，但是，土壤中的固体颗粒往往不是以单粒状态存在，而是形成大小不同、形状各异的团聚体。土壤中各种团聚体的排列组合状况，叫做土壤结构。土壤结构明显地制约着土壤孔隙状况，从而影响着土壤的肥力水平、微生物活性和耕作性能，对于土壤与环境之间以及土壤中的物质能量的迁移转化也产生深刻的影响。所以它也是土壤的重要物理性质之一。  

结构的形成必须有胶结物质和外力推动作用这两个因素。胶结物质中，无机胶体有粘粒、铁铝的氢氧化物、石灰等等，有机胶体有腐殖质、微生物菌丝体和粘液等等，其中腐殖质是最重要的胶结剂。外力的作用主要有胶体的凝聚作用、干湿交替作用、冻融交替作用和植物根系的穿插挤压作用等等，其中根系的作用颇为重要。  

由于土壤形成条件不同，土壤结构的形状、大小和稳定性是多种多样的。按生产意义划分，土壤结构可分为有结构和无结构两种类型。有结构土壤是指一部分土粒紧密排列成土团，具有水稳性特征，土团之间存在着相对稳定的结构孔隙，其容重较小，水气协调，是土壤肥力高的一种表征。通常以粒径为0.25～10毫米的水稳性团聚体作为大结构的指标，以0.25～0.001毫米水稳性团聚体作为微结构的指标。无结构土壤是相对于有结构土壤而言的，实际上也是有“结构”的，只不过它们是以单粒或粘闭大块状形式而存在，这样的“结构”易引起土壤的水、气矛盾，是肥力低的一种表现。

片状结构：结构体沿水平轴即长、阔的方向发展。按其厚度可细分为片状、板状、页状和鳞片状等。这种结构体多出现于冲积性母质层和耕作土壤的犁底层，其土粒排列紧实，常有碍于通气、

1(1一11)块状结构 Ⅱ(12-17)柱状结构 （18－22）片状结构透水和根系伸展。在雨后或灌水后往往在地表形成结壳或板结层，也可视为片状结构。  

棱柱状结构：结构体沿垂直轴即上下方向发展，不具圆顶，边面较明显，具光滑均匀的表面，边缘尖锐。这种结构易出现于粘质土壤的底土层。一般认为它是干湿交替作用的产物，故棱柱状结构体的大小可反映土壤水分变化情况。  

柱状结构：结构体亦沿垂直方向发展，但顶部浑圆而底部平，常见于半千旱地区含粉粒较多的底土层和碱土的心土层。这种结构的通透性较好，但易漏水漏肥。  

块状结构：结构体沿长、阔、高三轴平均发展，外形不规则，边面不明显。按块径大小可细分为碎块状、小块状和大块状等，易形成于缺乏有机质的粘质土壤中。块状结构多，是耕作质量差的一种表现。  

核状结构：结构体亦沿三轴平均发展，但边面较明显，形似核桃状，易见于粘质土壤中，多为石灰质或氢氧化铁胶结而成。  

团粒结构：结构体三轴大致相等，呈球状，球体疏松排列在一起，一经筛动，即可互相分开。湿时，结构体间的空隙不会因膨胀而闭塞。团粒结构多见于土壤表层，肥沃土壤中数量尤多。土壤中尚有许多粒径小于0.25毫米的微团粒结构，它既是形成土壤团粒的基础，同时，对土壤肥力的提高，也有一定的作用，特别在水田土壤中，这种微团粒结构更有其重要意义。  

一个土壤剖面可以是单一结构型的，但常见的乃是二种以上结构并存，通常土壤上层呈团粒状，中、下层呈块状、柱状或棱柱状，而片状等其他结构则多见于特定的土壤中。  

# 二、土壤有机质  

土壤有机质是泛指以各种形态存在于土壤中的各种含碳有机化合物，其中包括动植物残体、微生物体和这些生物残体的不同分解阶段的产物，以及由分解产物再合成的腐殖质等。可见，土壤有机质实际上是由一系列繁简不一、大小不等、性质各异、功能多样的各种有机化合物共同组成的一个混合体。  

虽然土壤有机质所占的份量远不及矿物质多，但它在土壤形成过程中的作用却是很大的。有机质是植物氮、磷、硫等营养元素的给源，并且作为生理活性物质而影响着植物的生长发育;更重要的是有机质特别是腐殖质本身的胶体特性对土壤的吸收性能、离子代换性能、与土壤全属离子的络合性能，以及对土壤缓冲性能等产生巨大的影响。有机质还与土壤团聚体和结构状况有密切的关系，从而又影响到土壤水分渗透、水分含量、耕性、通气性、土温、微生物活性，以及植物根系的穿插难易等等。由此可见，有机质对土壤肥力起着重要的作用。  

# （一）土壤有机质的来源和组分1．土壤有机质的来源  

土壤有机质主要来源于动植物残体，但各类土壤的差异很大。作为自然土壤的森林土壤和草原土壤，其有机质主要来源是生长在土壤上的自然植被之残体（地上部的凋落物和地下部的死亡根系及其分泌物）。而耕地土壤则除了作物收获后留在地下部的根茬外，主要是人工施用的有机肥料、绿肥，以及还田的秸秆等。这些有机残体进入土壤后，在土壤微生物的作用下，经历了一系列的变化，并不断地与土壤矿物质发生反应,形成不同状态和化学组成的土壤有机质，后者与进入土壤前的有机残体在性质上就大不相同了。  

# 2．土壤有机质的存在状态  

土壤有机质通常以如下几种状态存在于土壤之中：  

（1）生命体土壤中的各种活体，它们既可视为土壤中的一个独立的成分，又可视为土壤有机质的一部分。据估算，土壤中的生命体约占土壤有机质总量的0.56～4.6%，平均2.59%。这部分有机质主要附着在土壤矿物质或其他有机质的表面上。  

（2）机械混合处于未分解和半分解状态的有机残体，它们往往与土壤矿物质机械地混合在一起。这部分有机质可以利用重液(比重在1.8～2.03之间)将其分离开来。  

（3）溶液态或称游离态，土壤有机质中，有极小部分以溶解状态存在，如游离单糖、游离有机酸等等。·  

（4）有机——无机复合态这是与土壤矿物质相结合的有机质，由于有机、无机之间结合方式的不同，因而其结合的牢固程度也有差异。  

# 3．土壤有机质的化学组成  

土壤有机质通常可概分为两大类：一是普通的有机质，它们和有机残体的化学组成相似，如糖、蛋白质、木质素等等；一是特殊的有机质，即土壤腐殖质。从化学角度而论，土壤有机质是由碳水化合物、含氮化合物、含磷化合物、含硫化合物，以及腐殖质等组分组成的。  

（1）碳水化合物这是土壤有机质的一个重要组分。它既是土壤微生物的主要能源，又是形成土壤结构的良好胶结剂，因此，碳水化合物对土壤肥力水平有一定的影响。其含量大体上与土壤有机质总量相关，并随土壤深度的加深而减少。土壤碳水化合物主要是由多糖和游离单糖组成，前者多与土壤矿质成分或其他有机成分相结合，主要呈结合状态而存在；后者则以溶解状态存在，但其数量甚微。  

（2）含氮化合物氮是植物生长所必需的营养元素之一，是构成蛋白质的主要成分。土壤中的有机氮化合物不仅是植物氮素的主要给源，而且是地球生物圈中氮素的一种十分重要的存在形式。土壤的含氮量随土壤类型、土壤层次而异，其含量的高低及其变化规律大体上均与土壤有机质的状况相一致。  

（3）含磷、含硫化合物磷和硫也都是植物生长所必需的营养元素，土壤有机质也是硫、磷的主要给源。随着有机质的分解，土壤中含磷与含硫的有机化合物，将逐步分别转化为H2PO：和SO-，供植物根系吸收利用。  

（4）腐殖质腐殖质是土壤有机质的一个十分重要的组成成分，其含量约占土壤有机质总量的50～65%。土壤有机质和土壤腐殖质是两个不同的概念，前者是泛指以各种形态存在于土壤中的有机碳化合物，而后者则是前者之中特殊的暗色无定形高分子化合物。腐殖质仅仅是土壤有机质中的一个组分。根据腐殖质在不同溶剂中的表现，可分为三组：胡敏素（黑腐素）、胡敏酸（褐腐酸)和富里酸(黄腐酸），其中以胡敏酸与富里酸为主要。其分离方法如下：

# （二）土壤中的矿质化作用和腐殖化作用  

进入土壤中的各种生物残体在微生物的参与下，进行着矿质化作用和腐殖化作用。前者是有机质的破坏过程，它可以为植物生长提供相当数量的有效态的矿质营养元素；后者是腐殖质的形成过程，它可为土壤提供一定数量的腐殖质，以保持和提高土壤肥力水平。  

# 1．矿质化作用  

矿质化作用系指有机质在土壤微生物的参与下被氧化为最终的分解产物一—CO2、H2O、NH、H2PO、SO²-等的过程。  

（1）矿质化作用的两个阶段  

整个矿质化作用是分阶段完成的，一般可概括为如下两个阶段：  

第一阶段，为有机物质的降解阶段。有机物质被微生物体外酶逐步降解成为复杂有机质的基础有机化合物。也就是将大分子有机物降解成为小分子有机物，例如：蛋白质一→多肽→肽—→氨基酸。  

第二阶段，是微生物将第一阶段分解形成的简单有机化合物吸收至体内，其中一部分用于建造微生物的自身躯体，另一部分则被氧化为最终的分解产物。在这一过程中，微生物同时也获得了其生命活动所必需的能量。  

（2）影响矿质化作用的因素  

由于矿质化作用主要是在微生物参与下的氧化过程，因而，所有影响微生物生命活动的因素都是影响矿质化作用的因素。诸如生物残体的化学组成、土壤的温度、湿度、通气状况以及pH值等都影响着有机质的矿质化作用。  

在各有机组成中，糖和蛋白质属于易分解的物质，木质素及脂腊属于难分解物质，而纤维素则居于两者之间。因此，生物残体中各有机组分含量的高低，将直接影响着整个生物残体矿质化作用的难易和快慢。  

矿质化作用还受生物残体本身C/N（碳氮比，有机质中碳素与氮素总量之比）的影响。在矿质化过程中，微生物一方面从氧化含碳化合物而获得能量并利用一部分碳建造自己的躯体，同时它们还需要一定数量的氮。微生物分解25或30份碳素一般需要同化一份氮素，为此，生物残体的C/N在25：1或30：1时，最有利于它们的分解，如果C/N过大，微生物在分解过程中就会感到氮素的不足，其分解速度就要减缓，甚至停顿，而且微生物还可从土壤中夺氮，导致植物暂时性的饥饿状态。在生物残体的分解初期，微生物将大量繁殖，尤其需要同化大量的氮素。  

温度也是影响微生物活性和繁殖速度的一个重要因素。虽然微生物在0一45℃的温度范围内都能存活，但是，只有在25一35℃的适温范围内微生物的活动才能活跃起来，生物残体的矿化速率也较高。据研究，当环境温度在0一35℃范围内，平均温每增加10℃生物残体的矿化速率可增加二至三倍。  

土壤中适当的水分含量有利于土壤矿质化作用的进行，一般以田间持水量的50～100%为适宜。在水分含量适中，含氧量较高的土壤中，以好气微生物为主；在水分过多，含氧量不足的土壤中，则以嫌气微生物为主。土壤处于嫌气条件下，其矿质化作用的速度明显地低于好气条件。而且，分解产物也有差异：好气分解的产物主要是CO2、H2O、NO3、SO-；而嫌气环境下的分解产物，除了CO、H2O外，还有相当数量的中间产物，如R·NH2、R·SH、H2CH4、H2S、NH和各种有机酸，以及在嫌气条件下不易分解的生物残体和残留物。  

此外，土壤的酸碱性对于土壤微生物活动和矿质化作用也是有所影响的。但就多数土壤的pH值变动范围来说，一般尚不至于妨碍矿质化作用的正常进行。  

# 2．腐殖化作用  

腐殖化作用系指进入土壤中的生物残体在土壤微生物作用下转变为腐殖质的过程。这是一个较为复杂的生物化学作用过程，关于这一过程的实质和细节迄今尚无一致的意见。目前多倾向于苏联学者柯诺诺娃的看法，认为腐殖质的形成基本上分为两个阶段，第一阶段是在有机残体分解中形成了组成腐殖质分子的基本成分，如多元酚、含氮的有机化合物（氨基酸或肽）等。第二阶段是在各种微生物分泌的酚氧化酶作用下，将多元酚氧化为酿；

初始腐殖质的进一步合成，受进入土壤的有机残体种类、微生物的活性和水热状况等条件所制约。在森林植被、多水与酸性条件下,形成的腐殖质主要是较简单的富里酸;在草原植被、中性或碱性条件下，形成的腐殖质则以较复杂的胡敏酸为主。  

前面提及的影响矿质化作用的因素，同样也是影响腐殖化作用的因素。不过，凡是有利于矿质化作用的，几乎都有碍于腐殖化作用的进行。总之，生物残体的矿质化作用和腐殖化作用是同时发生的、既相互对立又相互联系的两个过程，这乃是土壤形成中最重要的过程。

# 三、土壤有机-无机复合体  

# （一）土壤活性的基础  

粘土矿物和腐殖质都是土壤中最细小的部分，呈胶体状态存在。由于它们的颗粒非常细小，而具有巨大的比表面（单位重量固体颗粒的总表面积）和表面能，并拥有表面电荷，能吸持离子和水分。土壤的许多理化特性明显地受粘土矿物和腐殖质的制约，它们是土壤活性的基础。  

从量上来看，腐殖质吸持养分与水分的量比起粘土矿物要多得多，但在土壤中通常都含有大量的粘土矿物，因此粘土矿物对土壤理化特性的影响，就总体而论，则与腐殖质相当。理想的农业土壤，其腐殖质往往是和粘土矿物融合在一起的，并持某种均衡状态。  

# （二）土壤中复合体的形成及其意义  

土壤中的粘土矿物和腐殖质很少单独存在，绝大部分是紧密结合为复合体状态。  

粘土矿物与腐殖质极为多种多样，相互结合的方式也相当复杂。一般而论，主要是由于新生腐殖质有着高度的活泼性和胶体性能，能与铁、铝的水化氧化物结合形成复合体；它还可以通过钙、镁、铁、铝(金属矫键作用)而附着于粘土矿物表面；或与蒙脱石、水化云母等粘土矿物相互作用、相互渗透，产生一系列错综复杂的物理、化学过程，从而形成复合体。此外，腐殖质还能以非极性吸附的方式，吸附于粘土矿物表面形成单分子层，这也就形成了土壤有机-无机复合体。  

土壤有机-无机复合体的状况，实际上，正是土壤矿物质、土壤有机质和土壤微生物等土壤组成成分对土壤特性影响的综合表现。可见，复合体乃是土壤肥力的重要物质基础。其意义可概括为如下几点：①复合体的团聚程度较高，所形成的土壤结构比较稳定。肥沃土壤的表层，通常拥有由团聚度高的复合胶体经逐级结合而形成的团粒结构。②土壤中粘土颗粒的粘结力和粘着力均较大，粒间致密紧实，给土壤带来不良的物理性质，但当它与有机胶体结合形成复合体后，能借助于有机胶体(特别是腐殖质)优越特性的调剂，以改善土壤的物理性质。③复合体可以通过改善土壤结构，降低土壤容重，优化土壤孔隙状况，进而使土壤的一系列理化性质发生重要的变化。①复合体具有集中和保蓄土壤养分的作用，可增强土壤保肥、供肥能力。复合体还具有多种功能团，并能解离H+和（)H-，表现出两性胶体的特点，对土壤中酸碱度的变化，有着明显的缓冲作用，其对土壤微生物活动和土壤养分转化等方面均具有重要的意义。  

# 第三节 土壤胶体与土壤吸收性能  

# 一、土壤胶体  

# （一）土壤胶体的概念  

土壤胶体微粒作为分散相（分散质）分散于微粒间的土壤溶液（即分散介质或分散剂）中，成为土壤胶体系统。土壤胶体微粒的粒径一般在1一100纳米（nm）之间，按其性质可分为有机胶体微粒（如腐殖质）无机胶体微粒（相当于土壤中的矿质粘粒部分）和有机-无机复合胶体微粒三类。由这三类不同的分散相分散于土壤分散介质之中构成了对应的有机、无机和有机-无机复合三类土壤胶体。  

# （二）土壤胶体微粒的构造  

胶体微粒（胶胞）是由胶核、吸附层和扩散层等三部分组成（图1-12）。其中心部分为胶核，吸附在胶核表面的一层离子，叫做内吸附层，同时，还吸附部分相反电荷的离子，称为外吸附层。胶核与内、外吸附层共同构成了胶粒。由于内吸附层的离子数目多于外吸附层，所以胶粒是带电的，胶粒的电性与内吸附层相同。胶粒的不足电荷，由吸附层外的扩散层中的离子补偿。扩散层中离子的活性比外吸附层的离子大得多，极易与土壤溶液中的离子进行交换。

其次，土壤胶粒(微粒)带有电荷。土壤胶粒大部分都是负电性胶粒.其电荷来源，因胶体种类而不同，主要有：①从溶液中吸附离子或胶核表面分子解离，如硅酸胶体，腐殖质胶体等。②断键，即晶片断裂而产生电荷，如高岭石等。③同晶替代，这是2：1型矿物电荷的主要来源。由于多数胶体是带负电荷的，所以有人提出，可把土壤胶体简化为一种复合酸式盐类。此外，在土壤中也有一些带正电荷的和两性的胶体。正因这种带电性，土壤才有可能吸收、保持离子态养分，使之免遭淋失，并随时供植物吸收利用。  

再者，土壤胶体具有可逆和不可逆的凝聚作用和分散作用。土壤胶体存在着凝胶和溶胶两种状态。由溶胶变为凝胶，叫做凝聚作用；反之，由凝胶变为溶胶，叫做分散(或胶溶)作用。但并非所有凝胶都能再变为溶胶，有些是不可逆的，由Fe3+、Al²+、Ca²+、Mg²+等阳离子所引起的胶凝，一般都属于很难或不能再溶的胶体，所形成的土壤结构是水稳性的。而由一价阳离子如K+、Na+、NH所引起的胶凝则是可逆的。因此，土壤中只有这两种状态的胶体持适当的比例时，才不致使保、供肥发生矛盾，并具良好的性状。  

# 二、土壤吸收性能  

# （一）土壤吸收性能的种类  

土壤中的微团聚体、土体的细微孔隙和高度分散的胶粒表面等，均具有吸收和保持（吸附）气体、液体、分子、离子或其他胶体粒子等的功能，这种功能就叫做土壤的吸收性能。通常，土壤具有五种吸收功能：  

1．生物吸收植物根系和土壤微生物能选择吸收土壤中的有效态养分，使之不易被流失掉。植物根系还可将底层的养分集中于土壤表层。  

2.机械吸收土壤象个过滤器，它可机械地阻滞较粗的物质（如悬浮物），使之不致流失。  

3．物理吸收土粒表面对界面上的分子态气体和水汽等，可借助于表面能进行吸附。如土壤反潮现象便是吸附水汽的结果。  

4．化学吸收溶于水中的物质与土壤胶体发生化学反应，可令易溶性物质变为难溶性的，从而被固定在土体中。如磷的固定：

概言之,土壤胶体是土壤代换吸收作用中十分活跃、重要的物质基础，对土壤养分的保蓄和调节发挥着相当大的作用。其中又以新鲜腐殖质组成的胶体作用最为突出。  

# 第四节 土壤孔隙、水分和空气  

土壤是由土粒和团聚体构成的疏松多孔体，颗粒之间存在着大小不等的孔隙，它们是土壤水分和空气的通道和贮存库。土壤水分和空气都具有较大的活动性，在土壤孔隙中，彼此之间所占的体积和重量是相互消长的。  

# 一、土壤孔隙  

由于土壤中存在着不同形状、不同大小的土粒和结构体,这样，它们之间通过点、面接触关系，形成了大小不一的空间。土壤中的这些空间就是土壤孔隙，土壤中孔隙的形状是复杂而不规则的，通常把土壤的这种多孔性质，称为土壤的孔隙性。土壤孔隙性，包括孔隙的数量、大小和类型。其数量的计算常与土壤比重、容重有关。  

# （一）土壤比重  

土壤固体部分的重量与同体积水(4℃)的重量之比，称为土壤的比重(真比重)。测定土壤比重时，应排除土壤孔隙的体积。土壤比重的大小取决于土壤固相组成物质的种类和相对含量。土壤中各种矿物的比重不同，一般多在2.6上下，含铁矿物的比重可在3以上。土壤中的腐殖质的比重为1.25～1.40。因此,腐殖质含量低的土壤，其比重就较大些。  

各种土壤的矿物质成分和腐殖质的含量差异很大，因而各种土壤的比重很不相同。一般变动在 2.4(黑土)到 2.7(红壤)之间。在应用中，常以2.65作为土壤比重的平均值。  

# （二）土壤容重  

单位体积的原状土(包括固体和孔隙在内)的干土重(克/立米厘米），称为土壤容重（假比重）。土壤的干土重是指在105～110C温度条件下的烘干土重。土壤容重既然包括了孔隙所占的体积，因此它总是小于土壤比重的。土壤容重的数值变幅很大，常在0.9～1.8之间。这种变动是受土壤的质地、结构、有机质含量和固体颗粒排列疏密状况等多种因素的影响。如砂土，其分散度较低，粒间孔隙虽大，但总孔隙量少，所以容重较大；而粘土则相反。表土疏松且多含有机质，其容重较小；而底土则相反。通常耕作层的土壤容重多在 1. 0\~1. 4 之间。

# 二、土壤水分和土壤溶液  

土壤水是土壤的重要液相组成部分。它是植物生长所需水分的主要给源，也是植物吸收养分的主要渠道，它还密切地影响土壤微生物的活性，制约着土壤生物群体的类型。同时，它还是土壤中进行各种重要的物理、化学、生物过程不可缺少的条件。所以,土壤水的运动和变化，不但影响植物生长，也影响土壤中各种物质与能量的迁移、转化，从而也就制约着土壤的形成过程和成土方向。  

土壤并不产生水，只是能够储存水，而且水在土壤中不断运动，并作为自然界水循环的一个环节，在全球水循环中起着应有的作用。土壤水也不是“纯水”，而是含有各种“溶质”的“土壤溶液”。  

# （一）土壤水的能量概念  

土壤中水分的吸持和运动，植物对土壤水的摄取利用，以及植物体内的水分输送，最后通过叶面蒸腾使水汽“散失"于大气中，所有这些过程都是与能量有关的。一切物质，包括水在内，都有从高自由能水平到低自由能水平移动和变化的趋势。物质承受种种力的作用后，其自由能有所改变，同样，土壤水受各种力作用后，其自由能也是有所改变的。  

# 1．影响土壤水分自由能的力  

土壤孔隙是一个密如蛛网、相互连通的体系，其孔径的变化往往十分突然，相邻孔隙的粗细可相差很多倍，同时这些孔隙又是多向相通的。为此，土壤中的水分也就是以形状和厚度都极不规则的薄水膜或薄水层状存在的。这些水分有时是与固体颗粒交界，有时又是与空气弯月面交界。显然，这里存在着两种重要的影响土壤水分自由能的力。一是水和土粒界面上的吸附力，一是水和空气界面上的弯月面力(毛管力)。  

吸附力指的是土粒表面分子和水分子之间的吸附力，称为伦敦-范德华力，以及胶体表面电荷对水的极性引力。范德华力属短作用力，其吸附力甚强，达几千乃至上万个大气压；而极性力较弱，一般为几个至几十个大气压。在土壤毛管孔隙中，水和空气的界面呈弯月面形，在弯月面下，水承受着一种张力，这就是弯月面力，也叫做毛管力。弯月面力的大小与毛管孔径呈反相关，孔径愈小，弯月面力愈强。弯月面力可由几个或十几个大气压至1/3或0.05个大气压或更低。实践中，很难把吸附力与弯月面力严格地区分开来，所以常将两者总称之为基质力。无疑，基质力将明显地降低被基质(土壤固体)所吸附的或所吸持的那些水分的自由能。  

除了上述基质力外，由于土壤水并不是纯水，而是一种成分复杂的溶液，所以它还受溶质引起的渗透力的作用，一般土壤溶液非常稀薄，作用很弱，但在盐渍土中或干旱条件下，渗透力也可以产生很大的作用。渗透力的作用，也有降低土壤水自由能的倾向。土壤水普遍地受重力的作用，它有把水向下“拉"的趋势。因此，剖面中在高处的土壤水自由能比在低处的静水(滞水)自由能要高一些。自由能水平的差异正是水分流动的原因。  

# 2.土水势  

土壤水的自由能水平可用土水势来表示。土水势是以同温、同压和处于相同高度的纯、自由水作为参比标准的。在这个参比标准下，水势规定为零。所以，土水势的值并非绝对值，而是与上述参比标准的差值。由于土壤水在土壤中承受各种力的作用，使其自由能水平发生变化，这种变化主要是降低，因此土水势一般为负值。

# （二）土壤水分形态  

根据水分的物理状态和水分子在土壤中所受力的不同对土壤水分进行分类，一般可划分为以下几种主要类型：  

1．吸湿水土壤固体颗粒依靠其很强的表面分子引力，把大气和土壤空气中的气态水吸附和固定在土粒表面，形成很薄的一层水膜，就是吸湿水(吸着水）。土壤吸湿水含量达最大值时，称为吸湿系数(最大吸湿量)。土壤吸湿水含量因土壤胶体的数量与质量而不同，质地粘重及含蒙脱石多的土壤，其吸湿水含量较高。土壤吸附这种水分的吸力非常巨大，可达数十个到一万个大气压，而一般植物根部细胞的渗透压只在10一20个大气压之间，所以它不能为植物所利用。  

2.膜状水当吸湿水充满后，土壤颗粒周围还可牢固地吸持一定数量的液态水,加厚土粒外围的水膜，这种水分称为膜状水。膜状水的最大含量叫做最大分子持水量。土粒保持这些膜状水的力为6一31个大气压，而稍具活动性，有极少量水分可供植物利用。但其运动速度十分缓慢，植物对它的利用受到限制。当其供应速度低于植物体内耗水速度时，植物便开始出现萎现象。植物出现永久凋萎时（土水势为一15巴)的土壤含水量，称凋萎系数。  

3.毛管水当膜状水充满后，毛管孔隙靠毛管力而保持的水分，称毛管水。这种土壤水分具活动性，可向蒸发的和低湿度的方向运动，系植物有效水分的基本来源。毛管水有二种：一是靠降水或灌溉水供给并与地下水无关系的毛管悬着水；另一是由地下水层上升的毛管上升水，其上升高度因土壤质地和毛管孔隙的大小而不同。毛管悬着水的最大含量叫做田间持水量，它是旱地灌溉用水量的主要依据。当所有毛管孔隙都充满水分时，称为毛管持水量或最大毛管持水量，它是由毛管孔隙的数量所决定的。  

4.重力水当毛管孔隙全部充满水后，若再有水分补充时，则存在于大孔隙之中，并因重力作用而下移，成为重力水。当土壤孔隙全部充满水分时，称为饱和持水量或全蓄水量、饱和系数。当排水良好时，重力水很快流失，它乃是土壤不能保持、植物不能利用的一种水分；当排水不畅、土壤水分过多时，则成为渍水，影响土壤空气流通，为土壤不良的特性。  

此外，土壤水分中还有化学结合水、气态水及冰等形态，它们对植物都是无效的。  

# （三）土壤水分常数与土壤水分的有效性  

# 1．土壤水分常数  

土壤保持水分的能力可由含水量表达。土壤含水量的一定类型则与土壤水的主要形态相联系。如吸湿系数是土壤吸持汽态水的最大含量（水吸力约31巴)；凋萎系数是植物产生永久萎时的土壤含水量（水吸力为15巴）；田间持水量是指毛管悬着水的最大含量(水吸力约1/3巴)；饱和持水量是土壤所有孔隙全部充满水分时的含水量，等等。这些含水量的数值乃是土壤水分形态分类的转折点，或土壤吸水力的转折点，所以叫做水分常数。当土壤水分含量达到饱和持水量时，土壤中含有吸湿水、膜状水、毛管水和重力水等类型的水分；当达到田间持水量时，则含有吸湿水、膜状水和毛管悬着水等类型的水分。余类推。

性，从而形成了土壤溶液。可见,土壤水实际上乃是成分复杂多样的“土壤溶液”，它含有各种无机盐类和可溶性有机化合物。无机盐类主要是钙、镁、钠、钾等的硝酸盐、亚硝酸盐、重碳酸盐、碳酸盐、氯化物、硫酸盐、磷酸盐等等，此外，尚有铁、铝、锰等的化合物；有机化合物主要是可溶性糖、蛋白质、氨基酸及酰胺等等。这些物质既有离子态、分子态的，也有胶体状态的，同时，由于土壤水有膜状水、毛管水和重力水等形态，各种物质溶解在这些不同形态的土壤水中，其浓度和溶解状态也很不相同。在这里，作为体系而言，土壤溶液体系乃是一个不均匀的溶液体系。土壤溶液是不饱和溶液，其渗透压一般低于一个大气压，并具有酸碱反应、缓冲性能等性质。  

土壤酸碱度是土壤重要的理化性质之一。它反映土壤物质组成的基本情况，反映土壤物质转化的动向，反映土壤空气、土壤溶液和土壤有机质、土壤矿物质之间物质交换的动态平衡。因此,常用酸碱性区分土壤，如酸性土、碱性土等。  

土壤溶液中氢离子的浓度直接影响着土壤的酸碱度。土壤有机质的分解，生成二氧化碳、氨和有机酸。二氧化碳溶于水生成碳酸，氨在硝化细菌作用下变为硝酸。此外，土壤中含硫物质可转化生成硫酸，含氯物质可转化生成盐酸，植物根系和微生物呼吸亦可产生碳酸。这些酸类的存在，使土壤溶液中氢离子浓度增加，而增强了土壤酸性。当土壤溶液中氢离子浓度减少时，土壤胶体所吸附的氢离子，还可以解离出来补充到土壤溶液中，在这里，土壤溶液中的氢离子浓度与胶粒上氢离子解离度有一定的关系：

土壤溶液的酸碱度通常用pH值表示。pH值越低，酸度越强，pH7代表中性，高的pH值则属碱性范围。一般土壤的pH值常在 3一10 之间。土壤的酸碱度常划分为极强碱性（pH<4.5)、强酸性（pH4.5--5.5)、酸性（pH5.5—6.5)、中性（pH6.5—7.5)、碱性(pH7.5--8.5)、强碱性(pH8.5—9.5)和极强碱性(pH>9.5)等级别。  

土壤酸碱度对作物生长有直接的影响，不同植物都有其较适宜的土壤酸碱度要求，如茶树能适应酸性土，棉花的耐碱性较强，但一般作物在弱酸、弱碱和中性土壤上生长良好，过酸、过碱则对之生长不利。  

土壤具有维持酸碱反应相对稳定的能力，即它能调节因酸碱物质的加入而引起土壤酸碱变化的性能，这种性能叫做土壤的缓冲性。因为土壤胶体上有代换性阳离子的存在，土壤溶液中含有各种弱酸和各种强碱弱酸所形成的盐类，它们能够起中和作用。土壤的物理吸收性能和两性物质的存在也能起缓冲作用。但土壤的缓冲作用有一定的限度，且各种土壤也有所不同。一般来说，缓冲能力的大小，主要取决于土壤胶体，特别是有机胶体含量的多少。  

在土壤和土壤溶液中，还经常而普遍地进行着氧化还原作用。其氧化作用主要是由自由氧、NO：和高价金属离子所引起;还原作用是某些有机质分解产物，厌气性微生物生命活动以及铁、锰等金属低价氧化物所引起。土壤作为一个多种氧化还原并存的体系，其氧化还原能力常用氧化还原电位(Eh)来表示(单位：毫伏)。从 Eh 值的大小，可得知氧化还原的状况:Eh 值愈大,氧化作用越强，反之，越弱。一般土壤的Eh 值在 200—700毫伏间,若Eh 值<200毫伏，则表示土壤中进行强烈的还原作用，这时有机质分解缓慢，还原性物质在土中积累可达到危害植物的程度；若Eh值>700毫伏时，土壤接近完全好气性，有机质迅速分解，营养物质易于流失。在农业上，适时灌溉和施用新鲜有机肥料等，可降低土壤的Eh 值；松土，排除渍水和降低地下水位等,则可提高Eh 值。这种调节措施可为作物生长提供有利的条件。  

# 三、土壤空气  

土壤空气是土壤中三相物质组成之一，它和土壤水共同存在于土壤孔隙之中，是土壤肥力因素之一。  

# （一）土壤空气组成的特点  

土壤空气基本上来自大气，但和大气不一样，有一部分气体是土壤中进行生物化学过程的产物。土壤空气有三大特点：①土壤空气存贮于土壤孔隙中，各孔隙内的空气成分有所差异，局部孔隙里，发生气体的反应，将影响土壤空气的组成成分；②土壤空气中的水汽含量比大气高，在土壤水分适中的情况下，土壤空气总是或近于饱和的；③土壤空气中的二氧化碳含量比大气高，而氧的含量比大气低，而且土壤空气中还有H2S、CH4、NH和 CO等生化过程产生的气体。  

# （二）土壤空气与大气的交换  

土壤空气与大气不断地进行着气体交换，土壤空气并借此而不断更新。其气体交换方式有二：  

1．整体交换土壤空气在温度、气压、风、降水或灌溉等因素的影响下，整体排出土壤，同时大气也整体进入，称整体交换。如表土温度高于大气温度，土壤内空气受热膨胀而被排出；风可把土壤空气整体“抽”出；降水或灌溉可把土内空气整体挤出，气压升降也有类似的作用。  

2．气体扩散这是土壤空气与大气交换的主要方式。土壤空气与大气中二氧化碳和氧的浓度不同，根据气体运动规律，气体总是由浓度大的地方向浓度小的地方扩散。所以土壤中较高浓度的二氧化碳，总是向大气中扩散；而大气中的氧也总是不断进人土壤中。这种土壤的不断地呼出CO2和吸入O2之过程，常被称为“土壤呼吸”。因此，土壤空气中的CO2含量才不致累积过多，而O2含量也不至于过少。  

不论气体是整体地进行交换，还是部分地相互扩散，它们都是要通过土壤孔隙的。所以土壤孔隙的数量、大小与孔隙之间的沟通状况，乃是气体交换能否通畅的主要原因，而土壤质地和结构同土壤的孔隙状况密切相关，这就影响到土壤的通气性能。砂质土和具有团粒结构的土壤，疏松多粗孔隙，通气性良好；粘质土和紧实的土壤，则通气性不良。  

在土壤中,土壤空气和土壤溶液、固相物质等,相互之间也进行着物质的交换，一部分气体不断被固相、液相物质所吸收,同时也有一部分气体从其中逸散出来。  

水分和空气在土壤中是两个相互矛盾的因素，在一定的空间，水分多空气就少，空气多水分就少，这种土壤水、气含量的对比关系深刻地影响着土壤的热量状况。土壤中固、液、气三相组分的热容量(单位:卡/立方厘米·C)和导热率(单位:卡/厘米·秒·C)都有很大的差异：固体为0.5—0.6和0.004--0.005；水分为1和0.0012；空气为0.003和0.00005。土壤水分热容量比空气大三千多倍，水分导热率比空气大25倍，在土壤三相物质组成中，固体部分的数量变化不大，因而土壤热学性质主要决定于土壤水、气的对比含量。通常湿度大的土壤，其含水量高，热容量和导热率都较大，土温不易上升。而且当土壤蒸发时，还要从土壤中吸收热，这是水分使土温不易升高的重要原因。炎夏之时蒸发强盛，灌水可降低和稳定土壤温度。相反，干燥的土壤，由于水分少，热容量小，导热率低，蒸发量也少，土温易于升高，但也易于降低，故温度变幅大。理想的情况是要求土壤中水、气经常保持适当的比例，这样既能保证作物对水、气的需求，又能具有有利于作物生长的适宜土壤温度。  

总之，土壤是个多相分散体系，由无机和有机固体、液体和气体物质所组成。各成分间皆按一定的比例组合成各种土壤。在主要组成中，特别是土粒粗细及其比例（机械组成），有机质与矿物质的比例，以及与土壤孔隙状况有关的土壤空气与水分的比例等，它们之间的相互配合情况对于整个土壤理、化、生特性有着决定性的意义和影响。·

# 第二章 土壤的形成  

# 第一节 岩石风化与风化产物  

# 一、风化作用  

风化作用可分为物理风化和化学风化。至于生物的活动（生物风化），就其对岩石和矿物的作用性质来说，也是以物理的或化学的方式作用于岩石或矿物的。从原始幼年土的形成来看，风化过程先于土壤形成，风化过程产生了形成原始土的母质，这样，风化过程可以认为是土壤形成的基础。从现代土壤的形成与发展来看，风化过程则应是成土过程本身的一部分。  

# （一）物理风化作用  

物理风化又称机械崩解作用，主要是由于地表的一些物理因素如温度、水、风等作用所引起的。这一作用的结果，使岩石由大块变成碎块，再逐渐变成细粒，从而产生了对水和空气的通透性，而且暴露的表面积也增大了，为化学风化创造了条件。  

# （二）化学风化作用  

化学风化又称化学分解作用，它的主要作用乃是水的作用。二氧化碳和氧也是化学风化的重要因素，但只有在水的参与下,它们才能充分地发挥其作用。

# 二、风化过程的阶段性  

岩石风化过程是分阶段进行的。苏联波雷诺夫将风化过程分为碎屑、钙淀积、饱和与酸性硅铝、富铝化等阶段。这种阶段的划分适用于残积景观条件。只有在湿润热带气候条件下，经历长时间的连续过程，才可完成这些阶段。  

# （一）碎屑风化阶段  

主要是在物理风化作用下，岩石矿物机械破坏变成碎屑，形成碎屑风化壳。此时岩石表面常为地衣所覆盖，它在岩石机械破坏和生物化学变化上发挥其独特的作用。碎屑风化壳中细土很少，主要是粗大的岩石碎块。  

碎屑风化壳广泛分布在年龄山区，特别是在高山区和两极地区为普遍，这些地方机械破坏作用强烈，化学风化作用微弱。在地形切割严重的地方，在重力作用下。风化产物经常崩坠，使风化壳不断更新，因而碎屑风化阶段可较长久存在，成为一种稳定状态。此外，在岩石裸露的干旱荒漠区，也可形成碎屑风化壳。在气候湿润的地区，碎屑风化阶段是非常短暂的。  

# （二）钙淀积风化阶段  

这是在干旱条件下，由碎屑风化阶段发展而来的第二个风化阶段。这一阶段化学和生化作用有所加强，原生矿物遭到分解破坏，最易移动的元素Cl、S及一部分Na从风化产物中淋走，一部分 Cl、S 为有机体所吸收。Ca、Mg、K等大部分保留在风化壳中，并有一些在风化过程中游离出来的钙离子与碳酸作用生成不易溶解的CaCO3，以白色薄膜包裹于碎块表面，或以白色粉末状细粒充填于缝隙之中。在土壤和风化壳中堆积CaCO;的现象，是干旱条件下风化作用的特征，故称为钙淀积风化阶段，形成碳酸盐风化壳。  

Ca 决定这种风化壳的地球化学特征，在Ca的影响下，土壤和地下水均呈中性至碱性反应，吸收性复合体几乎全为Ca、Mg所饱和。由于Ca是一种良好的凝聚剂，使得流经这种风化壳分布区的水显得清澈。因此，可以把Ca看作碳酸盐风化壳的标志元素。在草原和荒漠地带，风化壳中的CaCO;是稳定的，这一风化阶段能够较长期地维持。  

# （三）饱和与酸性硅铝风化阶段  

在降水量大于蒸发量的湿润气候条件下，风化壳受到强烈淋溶，可溶性风化产物不断淋走，风化过程释放出的Ca、Mg、Na、K很快被淋失,硅酸盐和铝硅酸盐分解生成的硅酸也被移走。风化壳中的阳离子显著减少，堆积在风化壳内的主要是伊利石、高岭石等次生粘土矿物。由于风化过程中盐基大量淋失，并相对地堆积了Si、Al、Fe组成的次生粘土矿物,故叫做硅铝风化阶段,形成了硅铝风化壳（或称粘土风化壳）。  

在这个阶段，含二价铁的矿物风化较为迅速，它从硅酸盐晶格中分离出来，从亚铁转变为高铁,形成了游离的Fe(OH)3，使风化壳染上特有的棕色或红综色。  

这一风化阶段的发展，经历了两个分段：初期，岩矿中尚有相当丰富的Ca、Mg，吸收性复合体为之所饱和，溶液呈中性反应，称为中性（饱和)硅铝风化阶段；之后，随着Ca、Mg 的淋失，吸收性复合体上拥有了代换性H+、A1²+，溶液中酸性加强，而称为酸性（不饱和）硅铝风化阶段。  

硅铝风化阶段显著的地球化学特点是 Cl、S、Ca、Na、Mg、K 等最易移动的和易移动的元素大量从风化壳中淋走，移动性小的元素相对累积。由于风化壳缺乏盐基，吸收性复合体不饱和，代换性H+、Al²+聚积，风化壳及地下水呈酸性反应。这时，H+的存在决定着硅铝风化阶段的地球化学特性,H+乃是这个阶段的标志性离子。  

硅铝风化壳广泛存在于湿润气候地区，厚度达几米，风化壳上层可能为粘土与壤土，也可能杂有大量岩石碎屑。  

# （四）富铝化风化阶段  

这是风化的最后一个阶段，由硅铝风化阶段发展而来，风化过程中不仅盐基大量淋失，而且铝硅酸盐分解生成的硅酸也大量淋失，残积层中的主要成分是Al2O和Fe2O3，它们彼此分离并分别富集，富铝化即由此得名。由于含有Fe2O，水化物，常使风化壳染成砖红色，称之为砖红壤风化壳。  

富铝风化壳相当深厚，常达几十米，甚至几百米，呈酸性反应，胶体特别丰富，主要次生矿物有水硬铝石、水软铝石、水铝矿、褐铁  

矿、硬锰矿、伊利石与高岭石等。  

富铝风化壳形成于高温多雨的热带气候条件下，在这种条件下才有可能发生强烈的风化和强烈的淋溶；同时还要经历长久的地质年代，要有稳定的地质构造和平缓的地形，只有这样，才有利于深厚的富铝风化壳的形成。

成土因素学说是现代土壤学的重要原理之一，它指出了土壤是各成土因素综合作用的产物，而且各种成土因素所起的作用是互相不能替代的。自然土壤的成土因素主要有气候、生物、地形、母质和时间。以后的土壤学者对成土因素的作用，有些不同的见解，如苏联格林卡认为母岩特性十分重要；涅渥斯特鲁耶夫强调地形的作用；威廉斯提出生物活动是主导因素；柯夫达认为在成土过程中还应考虑上地的地球内部深层因素（如火山、地震、新构造运动，等等)对土壤形成的影响。此外，还有人认为，土壤是一个“科学有机体”，在一定程度上有它自己的动力机制，在成土过程中，土壤本身也就是一个“成土因素”。  

除了自然成土因素外，人类活动的影响应当加以重视。  

# 二、自然成土因素在成土过程中的作用  

# （一）气候因素  

气候对土壤形成的影响主要是通过温度、湿度、降水和蒸发等因素而起作用的，即水热条件及其动态的组合。  

1．气候直接影响土壤的水、热状况  

（1）土壤热状况一般来说，温度增加10℃，化学反应速度平均增长1～2倍；温度从0℃增长到50℃时，化合物的解离度增加7倍。因此，热带地区岩石风化速度和土壤形成速度，以及风化壳和土壤的厚度，均比温带和寒带地区大得多。土壤热状况首先决定于地理位置。在不同的纬度地带，土壤的热状况不同。同一纬度地带，从沿海向内陆，土壤温度的年变幅和日变幅均有相应增加的趋势。土壤热状况可分为三个类型：  

受热的类型：土壤表层的年均温较土壤深处高。在干燥的暖温带或热带、亚热带地区比较显著。  

冷却的类型：土壤表层的年均温比土壤下层为低。在寒温带和寒带，尤其积雪地区更为显著。  

热平均分配类型：在中纬度降水丰沛的湿润地区，土壤表层与深层的温差不大。  

（2）土壤水分状况：水分对土壤形成过程起着巨大而又十分复杂的影响。降水集中且多暴雨的地区，易引起水土流失；含易溶盐多、矿化度高的地下水,可引起土壤的盐渍化过程。根据气候对土壤水分状况的影响，可分为以下几种土壤水分状况类型：  

淋溶型和周期淋溶型：降水量大于蒸发量的地区，雨季或融雪期间，土体中以下行水流为主，导致水溶性物质的淋溶，使土壤具有盐基饱和度低、酸性强等特点。森林土壤属于此种水分状况类型。  

非淋溶型：在年降水量低于年蒸发量的地区，降水因蒸发、蒸腾而大量消耗，水分只能下渗到有限的深度，未能湿润底土层，因而石灰、石膏等盐类在一定深度的土层内淀积。干旱和半干旱的荒漠土与草原土壤常为此种类型。  

上升水型：干旱或半干旱地区的地形低洼处，在地下水埋藏较浅的条件下，因蒸发强烈，毛管上升水可达到地表，草甸土即具此种水分状况类型。如果地下水矿化度高，则将导致土壤的盐渍化。  

停滞水型：气候湿润，排水不良地区，土层中水分的停滞时期较长。沼泽化土壤是此种水分状况类型。  

2．气候制约着土壤的形成过程  

气候对成土过程的影响，是相当复杂的。它一方面通过水热条件，制约着土壤中有机质的转化、矿物质的风化和迁移以及土壤水分的动态(运动的速度与方向)，从而直接影响土壤的形成、发育；  

另一方面则是通过光、热、水分等条件影响生物，特别是影响植物的生长、繁殖和种群组构等，从而间接地通过植物群落（或生物群落）而制约土壤的形成过程。  

3．气候控制着土壤形成的方向及其地理分布  

气候因素决定着成土过程的水热条件，直接影响到土壤内部水、气、热状况及其变化,直接、间接地制约着土壤物质的组成和变化。可以认为，气候条件是土壤中的物理、化学、生物作用过程的推动力，它深刻地影响着成土过程的强度和方向。与此同时，气候和生物一起共同决定了土壤地理的分布规律，尤其是地带性分布规律。  

此外,气候因素对风化壳类型、土壤粘土矿物的形成、土壤有机质的分解与积累、土壤微生物的数量与种类以及土壤中物质的迁移等诸方面的影响也是显而易见的。  

概言之，气候因素对土壤形成的影响广泛而深刻，其中有的是直接的，有的是间接的。从某种意义而论，似乎其间接的影响更为丰富多采，起着宏观控制的作用。  

# （二）生物因素  

生物因素是影响土壤发生发展最活跃的因素。由于生物的作用，才有可能将太阳能引入成土过程的轨道,才能使分散在岩石圈、水圈和大气圈中的多种养分物质向土壤(特别是向表土层)聚积并产生腐殖质，形成良好的土壤结构，改造原始土壤的理化性态，从而创造了仅为土壤所固有的各种特殊环境。所以，在一定意义上说，没有生物的作用，就没有土壤的形成过程。  

# 1．植物(植被)在成土作用中的特点  

在这里，就森林植被和草原植被的作用特点分别加以讨论。  

（1）森林植被的作用特点森林植被的年生长量高，但残落物主要是枝叶的一部分和花果等。它们堆积在地面上形成土壤覆盖层，覆盖层的下部为半腐解的有机质层。其有机碳含量高，但厚度不大，疏松多孔，易吸水而利于淋洗作用，又易通气，适于好气微生物的活动,并有利于真菌类生长，生成酸性腐殖质。有机质中含单宁、树脂较多,在真菌分解下产生较强的有机酸,后者抑制了某些细菌的活动,又对矿质土粒进行酸性淋溶，使表土层的盐基淋失，铁、铝、锰也发生鳌合淋溶而下移。所以在森林植被的长期影响下,土壤可产生程度不等的灰化作用，即表土中的碱金属、碱土金属以及铁、铝、锰等元素的化合物被强烈淋失，表土层的下部形成灰白色土层(E层),呈酸性、强酸性反应,养分十分贫乏。  

在木本植物中，阔叶树类的灰分所含钙、镁等盐基元素较针叶树类丰富，而残落物中单宁、树脂类则较少。所以阔叶林下酸性淋溶作用较弱，相对地，针叶林下的酸性淋溶作用则得到强烈发展，形成了强酸性土壤(如灰化土等)。总之,木本植被下有机质多聚积于表层，且厚度不大，土壤剖面中有机质含量的分配，往往是自表土而下急剧地减少，再者，森林土壤的有机质总量、有机质的品质均低于草原土壤。  

（2）草原植被的作用特点草原植物的地上和地下部分每年都经历全部或大部的死亡而更新，其土壤有机质层较为深厚，土壤剖面中有机质含量的分配表现为自表土而下逐渐减少。其有机质含单宁、树脂较少，木质素含量也少，而以纤维素为高。残落物柔软而少弹性，在分解过程中不产生强酸性物质，并以细菌分解为主，所形成的腐殖质的品质较好。草本植物的众多须根死亡后可形成有机胶体，活根的伸展和分泌出多糖类化合物，都易同土粒结合成良好的土壤结构，土壤肥力水平较高。  

草原植被中草甸草原和干草原又有差异。草甸草原发育于较湿润的环境，植物生长量较高，生长期较长，枯死的草类由于后期的气温、土温较低，加上土壤水分较多，分解较缓慢，故土壤中积累了颇为丰富的有机质。干草原的特点正相反，有机质易遭矿质化，积累也相对较少，故腐殖质层相对较薄。  

# 2.微生物在成土过程中的作用和意义  

微生物对土壤形成、发展的作用主要是：分解有机质，释放各  

种养分；合成腐殖质，发展土壤胶体性能；促进矿质养分转化，使磷、硫、钾等矿质养分能为植物吸收利用；有些微生物能够固定大气中的氮，制造了土壤中的合氮化合物，等等。  

这里应着重指出，种类繁多、数量庞大的土壤微生物在物质生物小循环中，担当了分解者的职能，在此，微生物乃是十分重要的不可替代的一环。  

# 3.土壤动物的作用  

土壤动物种类多，数量也不少。动物残体也是土壤有机质来源之一，但数量上比植物少得多。然而，它们对土体中的物质迁移、转化，对土壤的组成、性质与形态特征等方面可以起很大的作用。例如，蚯蚓不仅能使深达4～5米的土壤上下混合，并且还能将土壤通过其肠道分解，造成独特的胶状有机-矿质混合物。在草甸土中，蚯蚓能在一年内将80～90吨/公顷的排泄物搬到地表，而在热带地区，年搬运量更达250吨/公顷之多。又如，有的草原地区，每公顷土地上黄鼠和鼠的洞穴多达3000～4000个，它们可将数米深，特别是50厘米处的土壤矿物质和有机质上下翻动，每公顷数量达数百方或更多，其对土壤的理化性质有很大的影响。  

# （三）母质因素  

通常，把与土壤形成有关的块状岩体称为母岩，把与土壤发生直接联系的母岩风化物称为母质。  

母质是在成土过程中被改造的主要对象。土壤就是以母质为基础，在气候、生物等因素的作用下，逐渐转变而成的。为此，母质对土壤的形成、发展和土壤性状特征等均有深刻的影响。这种影响愈是在土壤形成的初期愈是显著。而且母质的某些特征常常为土壤所继承。  

一般而论，土壤的基本类型及其分布主要受生物、气候因素的制约，但区域性的母质差异也有明显的影响。如我国南方红、黄壤地带中，在石灰岩母岩上则发育成石灰土；在第三系紫红色页岩或砂页岩上便发育成紫色土。再者，发育于新近堆积的沉积物上的土壤，显然地有别于残积母质上发育的土壤。这都表明了母质的差别对土壤形成的深刻影响。  

母质中矿物颗粒的大小及其抗风化能力，对土壤的质地与其他特性的影响也是显然的。母质中如果砂粒含量较多，土壤质地也就较粗，其通透性好，但养分贫乏；含粘粒较多的母质，情况往往相反。母质的矿物组成和化学成分，常直接影响土壤矿质养分的含量。在由基性岩石风化而成的母质中，盐基物质含量通常比酸性岩石风化母质的含量高，相应的土壤养分含量也多。另外，从母质风化释放出来的各种元素在成土过程中的作用也不相同。如硅、铝、氧三种元素是形成土壤粘土矿物的基本元素；钠和钾等碱金属离子是促进粘粒和腐殖质分散的主要离子；钙和镁等碱土金属离子则是促进粘粒形成团聚体的主要离子，它们对土壤结构的形成有重要的作用。  

总之，成土母质的类型和特点是多种多样的，对土壤形成、发育以及对土壤理化性质的影响也各不相同。同一母质类型在不同生物气候条件下可发育成不同的土壤类别。同样的生物、气候条件下，在不同类型的成土母质上,发育形成的土壤也有着不同程度的差别，但母质仅仅是母质，不等同于土壤，它只是形成土壤的一种基本因素和主要的物质基础。  

# （四）地形因素  

地形因素与母质、生物、气候等因素的作用不同，在成土过程中，它没有给土壤提供任何新的物质，但它仍然是影响土壤与其他成土因素之间进行物质与能量交换不可缺少的条件。它是通过别的成土因素而对土壤起作用的。如地形的高度、坡度和坡向等要素可对水、热、生物、矿质成分等物质和能量进行重新分配，进而影响到土壤中物质能量的迁移转化。地形支配着地表径流，影响着物质的搬运、堆积，使高的地形部位与低的地形部位之间的土壤具有共轭性。一般来说，正地形是物质与能量的分散地，负地形是物质与能量的聚集地，因而在正、负地形之间形成一个有着发生联系的分异系列。海拔高度的不同，从山麓到山顶，气候与植被发生有规律的变化，从而使山地土壤具有垂直分布的特点。  

地形发育对士壤的影响也是十分深刻的。由于地壳的上升或下降，制约着士壤的侵蚀和堆积过程，并引起土壤水、热状况和植被等一系列的变化，从而使土壤形成过程发生改变，出现了士壤类型的演替。例如，河谷地形因侵蚀基准面的下降，可引起土壤的演替，在不同的地形部位上可构成“水成土→半水成土→自成土”的土.壤发生系列（图2-1）。

# （五）时间因素  

时间因素是有别于其他成土因素的一类特殊因素。实际上它就是成土过程的历史背景。时间因素在成土过程中作为一个强度因子，反映出在各种成因、条件的共同作用下土壤发育所经历的阶段和效果。  

土壤的年龄通常分为绝对年龄和相对年龄两种。从土壤开始形成时起直至当前这段时间，称为其绝对年龄。相对年龄则反映土壤发育的阶段或发育强度，它可作为成土过程的强度以及发育阶段更替速度的指标。可见，土壤相对年龄不仅取决于土壤存在的持续时间（绝对年龄），而且也取决于各成土因素和土壤本身性质的变化情况。一般而言，在土壤个体发育中，土层分化愈明显，相对年龄愈长；反之，分化程度愈弱，相对年龄则愈短。此外，相对年龄还反映了在环境变迁中，土壤类型的阶段发育问题。  

土壤的阶段发育是指土壤性质和类型随时间的推移而发生的演化。例如珠江三角洲地区随着海滩向前扩展，土壤经过脱盐和脱沼泽化过程，土壤类型也从滨海盐土变为沼泽土再成为草甸土等阶段而演变。这个演变的快慢程度和阶段的差异就是相对年龄的差异。因此，绝对年龄相同的土壤，其相对年龄可以有所差别。  

# 三、人为活动对士壤形成和演变的影响  

除了上述自然成土因素外，人类活动对土壤的影响也是十分重要的，并有其特殊性。在人为作用之前，土壤的形成发育完全受自然环境的制约，自受人类活动的干预之后，其性状便可发生根本性的变化。随着社会生产力的发展和科学技术的进步，人为因素对土壤的影响愈来愈广泛、愈来愈深刻。人类活动不仅可改变自然环境条件，还可以改变土壤的内在性质。例如，施肥、灌溉、客土、施用农药和“三废”污染等都是人类在土壤中直接添加物质；而平整土地、修筑梯田、灌排配套、植树造林以及其他农业技术措施等，则是改变土壤的发育条件。这些均将导致土壤性质发生变化。如水稻土、旱作土、园地土和灌溉熟化的绿洲土等都是人类耕种活动的积极成果。因此，耕种土壤不仅是历史的自然体，而且也是人类劳动的产物。作为成土因素之一的人类活动，既不能将其纳入生物因素之中，也不能与其他自然成土因素相等同，而应视为是一种独特的成土因素。这是由人类社会经济条件和性质所决定的。  

在一定范围内，它是可以改变土壤形成的内因和外因的一个重要的成土因素。  

# 第三节 土壤形成过程  

# 一、土壤形成的基本概念  

土壤是自然界各成土因素综合作用的结果。自然土壤形成的基本规律可概括为地表物质的地质大循环过程和生物小循环过程的矛盾统一。这个规律具体表现在土壤肥力的发生和发展的过程中，其中植物有效养分的积累，又是这个过程的最大特点。  

# （一）物质的地质大循环在成土过程中的作用  

地质大循环是指岩石经过风化，其产物通过各种形式的剥蚀和搬运过程堆积在低洼的地方成为沉积物，并在一定的地质条件下，经过固结成岩作用成为沉积岩，再经地壳运动抬升出露于陆地表面。这个以地质历史时间为周期的过程称为地质大循环。其中以岩石风化和风化产物的淋溶剥蚀等地球化学过程对土壤形成的关系最为密切。  

风化过程在土壤形成中的作用主要表现在原生矿物的破环以及其中养分的释放，而且还形成了次生矿物。由此可见，风化过程对土壤系统来说，是一种重要的输入过程。而淋溶剥蚀过程则是一种重要的输出过程，它可使土壤系统中的物质流失，使有效养分不能集中于土壤表层。但正常的淋溶剥蚀作用可使土壤物质更新，保证土壤的正常发育；如果此过程发生停滞或加速，则可令土壤的止常发育发生变化。  

# （二）物质的生物小循环在成土过程中的作用  

生物小循环是指，主要通过植物从土壤中选择吸收所需的养分并储存于活质中，再以残落物的形式归还给土壤，并通过微生物等的分解而重新进入土壤中的过程。即通过生物的生长吸收、归还、分解三个环节完成一个生态周期的循环。这个循环具有范围相对较小、效率高的特点，对土壤肥力的发生发展以及腐殖质的形成和积累有着决定性的意义。  

# （三）大循环与小循环的关系  

在土壤形成与发育的过程中，主要涉及地质大循环中的风化和淋溶二个环节的物质流通，以及生物小循环的吸收、归还和分解三个环节的物质流通。这两类物质流通的方式、方向、速率和周转期均各不相同，但它们之间的关系又是十分密切的。  

风化产物淋溶剥蚀过程的主要方向是导致养分从土壤系统中的淋失和分散；而整个生物活动过程则主要是促进养分的保存和集中。在地球化学过程中，风化和淋溶剥蚀，两者往往不相协调，这里，植物的保护作用可以缓和淋溶剥蚀作用的强度，以调节风化和淋失之间的供求矛盾。生物过程的物质运动速率通常较快，周转期较短，它不但能把风化中释放出来的有效养分保存于有机体或土壤中，而且植物还可以保护土壤固体物质，使之免于大量流失。显然，生物活动过程正是与土壤中物质的流失作用相抗衡的调节机制。两者之间的关系是对立统一的。一般而论，如果生物作用强而流失作用弱时，则土壤中养分保存多，肥力发展较快；反之，若流失作用加强而生物作用减弱时，则土壤中的养分难以保存，土壤趋于贫瘠化;当两者势均力敌时，则处于平衡状态。这种平衡状态乃是暂时的、动态的，其中尚有高水平的平衡状态（湿润热带的某些土壤)与低水平的平衡状态(寒带地区的土壤)之区别。  

从地球发展的地质历史上来看，生物小循环是在地质大循环基础上发展而来的，没有后者也就没有前者，也不可能有正常的土壤发生、发展。而且，生物小循环又是整个地质大循环中一个较小规模的物质循环。从地质历史时期来说，它最终也将纳入大循环的行列之中(如煤的形成)。然而，不管怎样，在土壤形成过程中，地球化学过程只是形成成土母质，从而获得了初步的通透性和保蓄性，但它毕竟不是真正的土壤。在这里，只有生物小循环才有可能不断地从地质大循环（风化产物)中，累积一系列生物所必需的养分元素。即通过有机质的形成、累积、分解和腐殖质的生成，发生、发展了土壤肥力，从而使得岩石风化产物脱离了母质阶段，形成为土壤。概言之，地质大循环乃是土壤形成的基础，生物小循环则系土壤形成的核心。在土壤肥力的发生发展中，生物起着积极的、主导的作用。  

# （四）原始土壤的形成发育过程  

岩石经过风化成为母质。当母质中出现微生物活动时，就开始了土壤形成过程。最初在母质上出现的生物有机体，是无机营养型细菌（如铁细菌、硫细菌、磷细菌，以及能够吸收分子氮的无机营养型细菌等)，由于这种细菌的活动，使铁、磷、硫、氮等元素进入生物地球化学过程之中，同时也发生了有机残体的累积。生命的进程出现了能分解有机质的异养型细菌，它能分解自养型细菌所积累的有机质，把营养元素分解释放出来，随着有机质的分解，产生了大量的二氧化碳，从而加强了母质中碱土金属的移动性。这时又出现了藻类和地衣，这些低等植物与细菌、真菌一起共同构成陆地上的原始植物群落，从而开始了土壤形成的生物累积过程，这便是土壤发生发展的最初阶段，也是土壤肥力萌芽阶段，从而也为高等植物创造了生存的客观条件。这个原始土壤的形成过程，显然是与陆生生物的起源、演变和进化相关联的，并互为因果、互为条件。高等植物通过其发达的根系选择吸收营养物质建造自已的机体，从而将无机态营养元素转化为相对稳定的有机态物质，这时生物积累过程得到了进一步的加强。有机残体在微生物的作用下，一部分矿质化为植物可以直接吸收利用的养分元素；另一部分则经历了较复杂的过程重新合成为原先的母质中所未有的物质一-腐殖质。腐殖质的出现大大改善于土壤结构状态，形成一定数量的团粒结构，增强了土壤保蓄、供给和协调植物生长所需的水、肥、气、热的能力。因此从宏观历史来看，成土母质在生物活动的参与下，由低级到高级逐步发展为具有肥力特征的土壤。  

应当明确指出，自从地球上出现了绿色植物之后，土壤的有机质积累过程和地球化学过程是不能截然分开的，通常是同时同地反复交替进行。这两种作用过程既矛盾又统一，不断地推动着土壤的形成和发展。  

从纵观来看，由母质成为土壤须经历各个发育阶段，整个土壤的形成过程和发展方向的基本规律大体上是一致的，但从横观来看，由于各成土条件组合的复杂性和差异性，便决定了土壤形成过程总体中的具体内容、性质及其表现形式的多样化和复杂化。根据土壤形成中物质(含能量)迁移、转化过程的特点，可将土壤形成过程的总体，划分出几种主要成土过程。  

# 二、主要的成土过程  

# （一）灰化过程  

土壤形成的灰化过程，是指土体表层，特别是亚表层出现SiO2的残留，R2O；及腐殖质的淋溶淀积过程。这主要发生在冷湿气候和郁闭的针叶林植被下，由于有机酸(主要是富里酸)在下渗过程中，使上部土体中的碱金属和碱土金属淋失，土壤矿物中硅与铝、铁亦发生分离，即铁、铝成分在活性有机质的螯合作用下被迁移并淀积于下部，而二氧化硅则残留于土体上部，从而在亚表层形成一个富含SiO2无结构的白色淋溶层次，称灰化层。  

# （二）粘化过程  

土壤形成的粘化过程，是指土体中粘粒的生成和聚积过程，尤其在温带和暖温带的生物、气候条件下，一般在土体内部(20～50厘米左右)发生较强烈的原生矿物分解和次生粘土矿物的形成，或表层粘粒的向下机械淋移，从而在土体的心土层常有粘粒的明显聚积，形成一个相对粘重的层次，称粘化层。这一过程相当于粘土矿物处于脱钾而未达脱硅的阶段。  

# （三）富铝化过程  

土壤形成的富铝化过程,即土体中脱硅、富铝铁的过程。在热带、亚热带的生物气候条件下,土壤中原生矿物被彻底分解,盐基离子和硅酸均遭大量淋失，粘土矿物以高岭土占绝对优势，次生的铁、铝氧化物在士体中，特别在粘粒部分发生相对的富集，如果这个过程进行强烈，铁与铝将进一步分离，分别形成铝土矿和铁磐，土壤发育达到砖红壤化阶段。这类土壤中矿质养分贫乏，呈酸性，土色深红。  

# （四）钙化过程  

土壤形成的钙化过程，主要是指碳酸盐类在土体中发生移动和累积的过程。在干旱、半干旱气候条件下，土壤形成的水分条件是季节性淋溶，这样，降水只能淋洗从矿物风化过程中释放出来的易溶性盐类，而硅、铁、铝等元素在土体中基本不发生移动，钙、镁只有部分淋失，部分仍残留在土壤中。因此土壤胶体表面和土壤溶液中多为钙(或镁)所饱和，使土壤呈中性至碱性反应。土壤表层残存的钙离子与植物残体分解时产生的碳酸相结合，形成重碳酸钙。在雨季它自表层被淋移至土体的中、下部后又发生淀积作用，形成明显的钙积层。碳酸钙的淀积在过量施用石灰的水田中亦可形成。  

# （五）盐碱化过程  

盐碱化过程又称盐渍化过程。主要发生在干旱和半干旱地区以及滨海地区。当地表水、地下水和母质中富含盐分时，由于蒸发作用，可溶性盐分积聚于表层，遂使土壤盐渍化。其中盐化过程是指土体上部易溶性盐类的聚积过程。当其含盐量达0.2%以上因而危害作物正常生长时，就称为盐土。碱化过程则是指土壤吸收性复合体上钠的饱和度提高，使土壤呈强碱性反应，并引起土壤物理性质恶化的过程。当代换性钠占阳离子代换量的20%以上时，其pH值可高达9以上，对作物造成毒害，且土壤粘粒高度分散，湿时稀烂，干时结成硬块；在土体中出现碱化层。如典型碱土。在不合理的耕作灌溉条件下，地下水位上升，易溶盐类在表土层积聚，也引起土壤盐渍化，这称为“次生盐渍化”。  

# （六）潴育化过程  

土壤形成的育化过程是指土壤形成中由于下渗水或土壤滞水的积使得氧化-还原作用反复进行，从而发生较明显的铁、锰淀积过程。主要发生在直接受地下水浸润的土层中，由于地下水位的季节性升降，使该土层干湿交替，从而引起铁、锰化合物移动或局部淀积，形成一个呈有锈纹、锈斑以及含有铁锰积聚体的土层，称育层。  

# （七）潜育化过程  

土壤形成的潜育化过程，即指土壤在长期渍水条件下，土体几乎完全处于闭气状态，在嫌气微生物的作用下，有机质受嫌气分解，锰、铁等处于还原态，从而形成一个还原性物质多的呈蓝灰色或青灰色的还原层次，称潜育层。  

# （八）腐殖化过程  

土壤形成的腐殖化过程是指土壤在生物循环作用下,在土体中，特别在表土层进行的腐殖质累积过程。它是土壤形成中最普遍的-个成土过程。由于植被类型、生物量以及有机质分解情况不同，腐殖质累积的特点也不相同。腐殖化作用的结果,往往在土体上部形成一暗色腐殖质层。  

# （九）泥炭化过程  

土壤形成的泥炭化过程，即指有机质以植物残体形式的累积过程。主要发生于地下水位很高，或地表积水的沼泽地段，植物残体因嫌气环境条件下不能彻底分解，而以不同分解程度的有机残体累积于地表，形成一个泥炭层或粗腐殖质层。  

# （十）土壤熟化过程  

土壤熟化过程是指自然土壤在自然的和人为的因素综合作用下进行定向培育，使其成为适于作物生长的耕作土壤，即从生土变为熟土的发育过程。其中人为因素居主导地位。主要表现在三个方面的改变或改造。第一，通过耕作使土壤剖面构造发生改变；第二，消除土体中对作物生长有障碍的因素；第三,改善土壤的水、气、热状况及调节和补充土壤养分，使肥力达到最佳状态。熟化过程是随农业科技的发展日趋深化的。在各自然带或自然区，土壤熟化过程各有自己的特点。  

综上所述，土壤的形成有多种多样的情况，某一土壤的形成往往不是单一的过程，而是以某一种成土过程为主，同时还存在另外一种或几种次要的或附加的成土过程。例如，在红壤和砖红壤的形成过程中，不仅存在着强烈的富铝化过程，并常伴随有程度不等的腐殖化、粘化等过程；水稻土的形成，除了耕作熟化过程外，也还存在着腐殖化、潴育化或潜育化过程，等等。概言之，在大多数情况下，自然界中的各种土壤总是某种主要成土过程与某些次要的或附加的成土过程共同作用的结果。探讨土壤形成过程，可以为土壤的分类和分布、土壤的利用和改良，以及土壤区划和农业生产规划等方面的研究提供科学依据。  

# 三、土体分异和土体构型  

随着上述土壤形成过程的进行，势必引起土体的分异，形成了各种不同的土体构型(剖面构造）。  

首先，在土壤形成过程的总体中，各具体的成土过程，都相应地形成一个模式上层(该过程的典型土层)。无疑，这是导致土体分异的最基本的原因。其次，各具体的成土过程；都是土体中物质(能量)迁移、转化总过程中的一部分，尽管不同的成土过程都发生于土体内的某一层位，但任一过程几乎都与整个土体的物质(能量)运动相联系。例如，由灰化过程形成的灰化层，其下必然潜伏有淀积层。显而易见，任一具体的成土过程所形成的模式土层，都与上、下土层有着特定的发生上的层位联系。所以，成土过程中的物质(能量)的聚集、淋溶物的淀积，也是使土体发生分异的重要原因。第三，就某一具体土壤而论，正如上述，它往往是由两种或两种以上的具体成土过程综合作用下形成的，从而使得土体分异更加复杂化。概言之，各类型的土壤剖面都是由特定的、并有内在联系的发生土层所组成，这就形成了各具特色的土体构型。然而，总的来说,这里还是有-个最基本的A一B--C模式可以概括的(详见第一章第一节)。

# 第三章 土壤的类型与分布  

# 第一节 土壤分类问题  

# 一、土壤分类的概念  

土壤分类是土壤科学的基础和核心问题，也是土壤科学发展水平的重要标志之一。它是通过比较土壤之间的相似性和差异性进行的，也就是对客观存在的土壤进行区分和归类，系统地编排它们的分类位置，同时对所划分的土壤分别给予恰当的名称。这项工作可以比较全面地反映人们对于土壤这一客体的认识水平。对此，不仅需要土壤科学的理论作为基础，并且还要有严谨的科学分类方法。  

土壤是自然客体，又受人类活动的影响。用于分类的性质和条件极其复杂，加以分类的依据各家看法不尽相同，有的分歧还很大。因此目前国际上还没有统一的土壤分类原则、分类系统和命名。各学派采用的分类依据、分类系统也都不一样，其中主要分类体系归纳起来有以下几种：①以美国为代表的土壤诊断学分类；②以苏联为代表的土壤发生学分类，我国解放后的土壤分类也受其影响；③西欧的土壤形态发生学分类。  

# 二、中国的土壤分类  

我国土壤分类研究，近期有颇大进展。在以往分类工作的基础上，于1978年提出较新的《中国土壤分类暂行草案》。分类中主要依据土壤发生学原则，即把成土因素、成土过程和土壤属性（较稳定的性态特征)三者结合起来考虑，但以土壤属性作为土壤分类的基础。实际工作中，也只有充分掌握土壤属性的变化,才有可能实现定量分类。同时，这个分类把耕作土壤和自然土壤作为统一的整体来考虑，注意到生产上的实用性。  

这个分类是采用土类、土种为主的分段分类制。土类以上概括为土纲，土类以下细分为亚类；土种以下细分为变种(亚种)；土属乃是土类与土种之间的过渡单元。因此，《中国土壤分类暂行草案》的级别为土纲、土类、亚类、土属、土种和变种的六级分类制。  

现将分类级别及划分依据简述如下：  

①土纲：根据成土过程的共同特点加以概括。  

②土类：为分类的基本单元。它是在一定的自然条件或人为因素作用下形成的，具有独特的成土过程和土体构型。各土类之间有质的区别。如砖红壤土类是在热带雨林下高度化学风化，富含游离铁、铝的酸性土壤；水稻土土类是在水耕熟化条件下形成的，具有特定的土体构型的土壤，等等。  

③亚类:是土类中的不同发育阶段，或土类间的过渡类型。如黑钙土土类可续分为典型黑钙土、碳酸盐黑钙土、淋溶黑钙土、草甸黑钙土等亚类。  

④土属：是承上启下的单元。主要依据母质、侵蚀强度、耕作熟化情况等地方性因素划分。如红壤按母质影响分为铁质的、铁铝质的、硅铁质的等土属；盐土则按盐分组成来划分。  

③土种：是分类的基层单元。据发育程度或熟化程度划分。同一土种不仅母质相同,而且剖面构造特征也相似。如山区土壤可按土层厚度、有机质含量等的差异来划分；盐土则按盐化程度划分之，等等。  

③变种：是土种内部的变化，一般以表土层或耕作层的某些变化来划分。  

一个好的土壤分类系统还要有一个好的命名系统。我国目前建立土壤命名系统注意到如下几点：第一，土壤命名的字数和结构力求简明和系统化；第二，尽量从俗名中提炼；第三，与生产紧密联系，便于使用；第四，已习用的名称不宜轻易改动，以免造成混乱。  

“中国土壤分类暂行草案”采用分级命名法，即士类、土属、土种等都可单独命名，且习惯名称与俗名并用。高级分类单元（土类、亚类）以习惯名称为主，如黑钙土、褐土等，也有从俗名中提炼的，如黑泸土、白浆土等。在基层分类单元中，尤其是耕作土壤的土种、变种，主要是选用俗名。  

《中国土壤分类暂行草案（1978年）共分出46个土类，约142个亚类，土类以上又概括为 11个土纲（表3-1)。随着对土壤认识的加深，土壤分类势必有所发展，并日臻完善。

# 三、国外土壤分类简介  

# （一）苏联土壤分类现状  

道库恰耶夫及其后继者研究了土壤发生性状与成土条件，创立土壤地带性和以生物为主导的成土因素学说，奠定了土壤发生学分类的理论基础。1976年出版的伊万诺娃之《苏联土壤分类》一书，可以认为是当今苏联发生学分类的代表作。  

依万诺娃的土壤分类系统是以土壤发生学为依据，并考虑土壤形成条件、过程和属性等三个环节。这个分类系统共分出118个土类。土类是大的分类单元,发育在相同类型生物、气候和水文地质等条件下，具有明显一致的土壤形成过程。土类以下续分为亚类、土属、土种、变种和亚变种等。  

苏联的土壤名称采用连续命名法，即在土类名称的前面加上亚类的形容词，亚类名称之前冠以土属、土种的形容词，依次逐级连续拼接。例如，壤质深厚典型黑钙土就是一个变种的名称，等等。无疑，这种命名法可把各分类单元的基本特征反映出来，但其字数多，较累赘。  

苏联分类的特点在于，贯彻发生学原则，各级分类单元，特别是高级的分类单元，按土壤的发生演变规律来划分，它们之间关系清楚，系统明确。但其过分地强调了地带性成土因素的作用，忽视了土壤本身的属性在分类中的具体运用，因而出现了把非地带性土壤从属于地带性土壤等不合理现象。再则，苏联的各级分类单元的划分，仍停留在定性描述或半定量阶段，有待于向定量化方向发展。  

# （二）美国土壤分类现状  

本世纪五十年代早期，美国着手制订以土壤诊断特征为依据的土壤分类制，1960年刊出第七次修订稿，又在1964年和1967年加以补充，1975年写成《土壤系统分类》一书。这是以土壤的诊断土层和诊断特性为依据的土壤分类，称土壤诊断学分类。这些土壤特性可以直接感知和定量测定。  

美国现行土壤系统分类共分六级。土纲是根据部面分化、形态特征、主要发生层的发育程度，尤以诊断层的特征作为划分依据，为分类系统中的最高分类单元。美国共划分出10个土纲。土纲之下为亚纲、土类、亚类、土族和土系等。土系是分类系中的基层单元，同一土系的土壤，除表层质地外，剖面层次排列和性质均相似。美国已划出13000多个土系。土系之下尚可续分为土型等。  

土壤命名采用拉丁化,字头、字根拼接法。如Ent一—新成土土纲,接字头Aqu 则成Aquent 潮新成土（亚纲）,Cryaquent 即成冷潮新成土土类。土类前再加形容词，如Haptic 即成薄层冷潮新土亚类。这样，从一个名称的字头或字根上，也就能够明了土壤的主要性状了。  

美国土壤分类的特点是以诊断土层和土壤属性为根据，其系统明确，指标具体。正因基层分类单元的分类指标统一，其中已有近5000个土系的有关属性输入计算机贮存，而可按一定的程序进行自动分类。但美国的土壤分类所采用的指标过于繁杂，有些高级单元概括得太广，土系之间也缺乏联系。然而，它毕竟是一个朝着定量方向发展的分类系统。

# 二、土壤的水平分布规律  

土壤的水平分布规律，包括土壤的纬度地带性和土壤的经度地带性。  

# （一）土壤的纬度地带性  

由于太阳辐射和热量在地表随纬度方向发生递变，从而导致气候、生物等成土因素以及土壤的性质和类型也按纬度方向呈有规律的更替。这种现象称土壤的纬度地带性分异。如前所述，土壤的纬度地带性在欧亚大陆、非洲和北美东部表现得明显。如欧亚大陆之地势较平坦的苏联欧洲部分，从北而南依次出现：苔原带的冰沼士，太加林带的灰化土，森林草原带的灰色森林土，草原带的黑钙土，干旱草原的栗钙土，荒漠草原带的棕钙土和灰钙土，以及荒漠带的荒漠土。  

# （二）土壤的经度（地)带性  

主要由于海陆的差异以及大地构造和地形条件(尤其是纵向构造隆起带）的影响，使水分条件和生物等成土因素从沿海至内陆发生变化，土壤的性质和类型也相应地呈规律性的变化。这种现象即为经度（地)带性。如从沿海至内陆，常常可依次出现：湿润森林土壤，半湿润森林草原土壤，半干旱的草原土壤和干旱的荒漠土壤等。在此，它们大致呈南北向延伸，沿经度方向更替，于中纬度地区表现最典型。在此，还应注意到，各大陆的东岸、西岸和中部皆各有一系列纬度地带性土类的组合，分别构成了一套水平地带谱。

# 四、土壤的局地性分布  

土壤的纬度地带性、经度（地）带性和垂直带性均系厂域的土壤地理分布规律。在此基础上，尚有一系列土壤的局地性（地方性）分布形式。局地性分布主要是由中、小地形、水文地质条件、母质因素以及人类活动等所造成的。  

在中地形影响下，可引起水热条件和土壤组成物质的再分配，使土壤分布按不同地形部位呈有规律的组合。根据土壤组合的特点，可归纳为枝形、扇形和盆形等形式。  

枝形土壤组合：这种组合多见于高原与山地丘陵地区，由于河谷发育，随着水系的树枝状伸展，形成了枝状土壤组合形式。这种土壤组合，由地带性土壤、半水成土与水成土共同构成。  

扇形土壤组合：这种土壤组合主要是不同士壤类型沿洪积一冲积扇有规律分布。由于沉积物的分选，随地形降低而由粗变细，地下水位逐渐抬升，加上地球化学的作用，形成了一系列的扇形土壤组合。如天山南麓棕漠土带的新疆焉耆盆地，山麓洪积扇十分发育，许多扇形地自山麓向盆地中心伸展，从扇形地上部的棕漠土，向下依次出现草甸土、草甸盐土与盐土。  

盆形土壤组合：在湖泊和盆形洼地周围，由于地形由四周向中心倾斜，在地面水和地下水的共同作用下形成了一系列水成与半水成土壤，以湖泊水体为中心呈同心圆状分布，在这种地区便形成了盆形土壤组合。如内蒙古高原上的诺尔(湖泊)周围的土壤组合是由水体向外依次为沼泽土、盐土、草甸土、草甸栗钙土或草甸棕钙土以及于盆地周围的栗钙土或棕钙土等的分布。  

在较小地域中，因小地形、地下水或地面水状况的差别以及人类改造自然的结果，可形成阶梯式、棋盘式和框垛式等土壤的微域性分布形式。  

# 第三节 主要土壤类型  

自然土壤是气候、生物、母质、地形和时间五大自然成土因素综合作用的产物。由于各因素作用强度不是等同的，从而产生了不同的土壤类型和不同的分布形式。在此，可概括为显域性土壤和隐域性土壤二种。显域性土壤的形成过程主要受生物、气候因素所制约，其分布乃与生物、气候条件相适应。显域性土壤可划分为苔原土壤、森林土壤、草原土壤和荒漠土壤等发生系列。隐域性土壤主要是在母质、地形、水文地质等地方性因素的作用下形成的，它们以斑状形式星散分布于显域性土壤的“背景”之中。隐域性土壤可以分为水成土壤、半水成土壤、盐成土壤和岩成土壤等类别，山地土壤亦属之。  

水稻土是在人类生产活动一—水耕熟化过程中形成的，有别于自然土壤的一种特殊的土壤类型。  

# 一、苔原土壤—冰沼土  

苔原土壤是指在苔原植被下发育的土壤，其中主要是冰沼土（一）冰沼土的地理分布和形成条件  

冰沼土主要分布于北极圈以北的北冰洋沿岸地区，包括亚、欧大陆和北美洲的最北部，以及北冰洋的许多岛屿上。在南极洲也有分布。我国最北仍处于中纬地带，仅有山地冰沼土零星分布于某些高山的上部。冰沼土分布地区属苔原气候，年均温在0℃以下，一般为－10～一17℃，全年结冰期在8个月以上。冬长而严寒，夏短且凉爽。冬季气温可低至一40℃，甚至一55℃；夏季最热月份平均气温一般为10～12℃左右。降水量不多，年降水量在欧洲部分为200～300毫米，在亚洲大陆东北部则不到100毫米，但降水次数较多，加上气温低、蒸发弱，所以空气相对湿度大，其年变幅平均在75～90%之间。此外，云量多，风力强，也是这一地带的气候特点。  

由于气候严寒，生长期短，加上强风及永冻层的存在，故植被一般是不繁茂的。植物主要是地衣、苔藓和少量的灌木。由于这里脱离冰川覆盖不久，冰川地形保持得相当完整。土壤母质以冰物、冰水沉积物和残积物等为主。  

# （二）冰沼土的形成过程和基本性  

冰沼土带的生物、气候条件决定了这里的土壤形成过程特点。低温决定了这里的物理风化以冰冻风化为主，化学风化和生物风化很弱，母质风化程度低，土层浅薄，一般不超过20～30厘米。  

由于永冻层的存在，土壤过度潮湿或呈水分饱和状态，矿物质和有机质经常处于嫌气条件下。矿物质往往呈还原状态，铁、锰常被还原为低价态，土壤中形成了一个呈蓝灰色的潜育层。有机质形成的数量虽不多，但分解转化缓慢，土壤上部常有泥炭化和半泥炭化的有机物质累积。又因其成土年龄较短，土壤发育迟缓，许多地方的土壤仍处于原始成土阶段，泥炭化和潜育化作用的表现都很微弱。  

冰沼土腐殖质含量一般在1～2%左右，腐殖质组成中以富里酸占优势，盐基代换量低，呈微酸性至酸性反应。  

# 3.冰沼土的利用和改良  

冰沼土的自然肥力很低，环境条件严酷，一般无法农用。但这里生长着地衣，这是养鹿的主要饲料，所以，发展养鹿业乃是利用冰沼土的重要途径之一。  

# 二、森林土壤  

森林土壤是指在森林植被下所发育的土壤。森林土壤在世界上分布极其广泛，从寒带到热带的广阔范围内，凡是条件适宜的地方，均有分布，其约占全世界陆地的35%。我国森林土壤主要分布于东部广大地区和西南的云贵高原、四川盆地。此外，西部地区的山地垂直带谱中一般也包含有森林土壤。  

森林土壤的共同特点是：①气候湿润，淋溶作用强，土壤中盐基物质较少，土壤反应偏酸性。②由于淋溶作用较强，表土层物质下移显著，故土壤剖面中多有淀积层的发育。③有机质主要以枯枝落叶形式进入土壤，故腐殖质明显地集中于土壤表层，并向下急剧减少。在腐殖质中，富里酸常较胡敏酸为多。上述特点正是森林土壤与其他土壤不同之处。但在各森林土壤之间，仍然是各具特色的。。  

# (一）灰化土(附漂灰土)  

1．灰化土的地理分布和形成条件  

灰化土在地球上分布较广，在欧亚大陆和北美洲北部，呈连续带状;在南半球，由于相应的纬度地带为水域占据，故其灰化土甚少。我国未有典型灰化土的发育，但分布着类似于灰化土的漂灰土，主要见之于大兴安岭北端和青藏高原边缘的高山垂直带谱中。  

灰化土分布区的气候特点是低温潮湿。年均温在0℃上下，年降水量约300～600毫米，多集中于夏季；冬冻区面积较广，冬冻阻碍着土壤的发育，春融利于淋溶与潜育。其植被是以针叶林为主，主要由云杉、冷杉、落叶松和红松等种属构成。灰化土地带的地形和母质较多样，大多数脱离冰川覆盖未久，故冰川地形和冰物母质均较常见。  

2.灰化土类土壤的形成过程和基本特征  

灰化土的主要成土过程是灰化过程，这是因为其自然植被以针叶林为主。针叶树的残落物中富含单宁、树脂类物质，分解时造成了很强的酸性环境，其不适于细菌，而宜于真菌活动。有机残落物在真菌的作用下，一方面令有机质矿质化，释放出各种盐基，并产生了富里酸，这是灰化过程的重要条件，富里酸的酸性强，而针叶林残落物中盐基含量低，在低温潮湿条件下，残落物分解又相当缓慢，故释放出来的有限的盐基物质，不足以中和富里酸，于是游离的富里酸以及一些其他酸类能够随着下渗水分大量地进入矿质土层之中。酸性溶液进入矿质土层后，首先与土壤中的碳酸盐发生作用，引引起钙、镁碳酸盐分解，形成富里酸钙和富里酸镁，并随下渗水迁移，导致土壤中代换性盐基的淋失。富里酸还与铁、锰化合物作用，形成富里酸铁和富里酸锰，并下移，使土壤上层颜色逐渐变淡。富里酸与硅酸盐及铁、铝硅酸盐作用，并破坏高岭石。这时形成可溶性的铁、铝、硅氧化物及各种富里酸盐，以胶体溶液或真溶液的状态下淋，并析出非晶质粉末状的二氧化硅，形成白色片状结构或无结构的灰化淋溶层。富里酸钙、镁、锰、铁等盐类和少部分无机酸的盐类，以及铁、铝、硅酸等胶体物质，在其下移过程中，由于愈来愈多的盐基对酸性溶液的中和作用、溶胶物质之凝聚和淀积作用，以及嫌气性微生物的活动，而淀积了下来，从而形成了一个呈红棕色或红褐色的、比较紧实的层次——淀积层。  

概言之，灰化土的剖面形态分异明显。表层为泥炭状的粗腐殖质层；灰化层即直接处于表层之下，为灰白色、粉砂质、强酸性、具片状或无结构；灰化层之下为淀积层，质地较粘重、紧实、块状结构、中性反应。有时，剖面的下部还有一个蓝灰色的潜育层。  

# 3．灰化土的利用和改良  

灰化土类土壤，在农业利用上的缺点是，酸性强、结构差、植物养分贫乏。在利用中，应采取改良措施提高肥力，施用石灰以中和酸性，施用有机肥以改善土壤结构，等等。  

# 附:漂灰土  

我国寒温带湿润地区针叶林下发育的漂灰土，过去曾称作灰化土、生草灰化土等等。近期研究表明，漂灰土不同于灰化土或生草灰化土，而是生草灰化土和暗棕壤之间的过渡性土类。可以把它看作是地方性气候和植被影响下形成的一种特殊的土壤类型。漂灰土在我国主要分布在大兴安岭中北部，以及阿尔泰山和青藏高原东南缘的亚高山、高山垂直带中。大兴安岭中北部，年均温在0℃以下，年降水量在400～500毫米之间，大部分降落在6一8月。冬季严寒少雪，冻层可达3米左右，大兴安岭地区有岛状永冻层的存在。植被属针叶林，在大兴安岭以落叶松或樟子松林为主，其他地区多以冷杉林为主，地表有大量苔藓。漂灰土的形成有自己的特色：在长期冷湿条件下，森林凋落物分解所形成的酸性物质进入表土层后，可引起较强的酸性淋溶作用，但因土壤冻结和生物积累，使得被淋溶的物质又可部分地返回地表，阻止着灰化作用的深入进行。又因冻层造成土层滞水，且藓类凋落物具高度的持水性，造成了地表过湿，导致铁还原为亚铁而发生淋溶或随侧向水移动，令土层离铁褪色。显然，漂灰土的形成不仅有灰化过程，而且还有离铁作用，并以后者为主。  

在剖面形态上，漂灰土的地面常具木本调落物和苔藓类死亡部分构成的残落物层；腐殖质层，有时呈半泥炭化特征，为暗灰色或棕灰色；腐殖质层之下，逐渐过渡到灰白色的漂灰层，多为细粉砂质、呈灰白色或浅灰色；淀积层，呈棕色或黄棕色，紧实而较粘重，常含大量石砾，在石砾的背面可见到铁锰胶膜和暗色的腐殖质斑块，其下即接母质层。整个剖面分化明显，但总厚度不超过1米。这类土壤表层有机质含量为10～30%，向下锐减；但在淀积层中仍具一定数量的有机质。腐殖质组成以富里酸占绝对优势。土壤呈酸性反应，pH4.0～5.5。盐基饱和度低，甚至极度不饱和。  

漂灰土地带是我国针叶用材林重要基地之一，虽然林木生长缓慢，但在积极采伐过熟林的同时，注意及时抚育更新，保持水土和培育土壤肥力，木材仍可稳产高产。  

# （二）棕壤  

1．地理分布和形成条件  

棕壤又称棕色森林土,全世界分布很广。西欧各国如英、法和西德,北美洲和美国东部,亚洲的中、朝和日本等地均有分布。在我国，主要分布于辽东半岛、山东半岛及辽河下游平原等地区。  

棕壤，在世界范围内是温带海洋性气候、中生型落叶阔叶林下发育的土壤。我国的棕壤乃是在暖温带季风气候、落叶阔叶林下发育的。  

我国的棕壤分布区气候因受明显的东南季风影响，夏季暖热多雨，冬季寒冷易旱，年均温为5～6℃，全年降水量为500～1200毫米。天然植被主要是落叶阔叶林，其次为针阔叶混交林。地形以低山丘陵为主。母质多是残积物、坡积物以及黄土状沉积物等。  

# 2.形成特点和基本性状  

由于棕壤地区气候适宜，土壤中不仅粘化作用强烈，而且淋溶作用也相当显著，使得易溶性盐类和碳酸盐（主要是石灰)均遭淋失，粘粒沿剖面下移并发生淀积。由于阔叶林的残落物含较丰富的盐基物质，而有助于土壤中盐基的生物循环，故土壤上层代换性盐基含量较高，能中和各种酸类(包括富里酸)，使得粘土矿物免遭酸性溶液的破坏，从而阻止了灰化作用的深入进行。  

棕壤剖面主要呈棕色或浅褐色，整个土体均较粘重，无游离碳酸钙，具中性至微酸性反应。剖面层次分化的情况是，土壤表面有一森林残落物层，其下有四个层次：表层是腐殖质层，厚约15～25厘米，颜色较暗；中部为棕色的淀积层，质地明显粘重；再向下乃是向母质过渡的层次和母质层。  

# 3．利用和改良  

棕壤的有机质和矿物质养分含量并不很高，但所处的气候条件较适宜，通常有较丰富的土壤水分，对施肥反应较快，宜于种植多种农作物，盛产玉米和小麦，这类土壤在农业利用上占有重要地位，但冬季往往土温过低，作物不能生长，常为一年一熟。  

# （三）褐土  

# 1．地理分布和形成条件  

褐土又称褐色森林土或褐色土。在欧洲，褐土主要分布在地中海沿岸的法国南部、巴尔干半岛;在苏联，见于外高加索、克里米亚；在非洲，分布在北部沿地中海地区。处于亚热带地中海型气候区，天然植被主要是旱生型森林或灌丛。  

我国的褐土分布区则属于欧亚大陆东部暖温带大陆性季风气候，植被为旱生落叶阔叶林与灌丛。且多发育在各种碳酸盐母质上。  

# 2.形成特点和基本性状  

褐土带和棕壤带的不同点是温度较高，降水较少，夏季较炎热，一年中有明显的旱季。褐土形成的基本特点是兼有粘化和钙化二个过程。与此同时，也有一定的淋溶作用，只是不如棕壤强烈，故在一定深度处，有碳酸钙淀积的层次。褐土的粘化作用尚属明显，作用强度较棕壤弱，但仍可在钙积层之上出现一暗棕色的粘化层。我国褐土分布区水热条件是以夏湿冬干，高温与湿润同时发生为特点，其风化与成土过程主要在夏半年进行，这与地中海地区褐土有着明显的区别。但是，不管怎样，它们的土壤剖面层次分化是相类似的，即由腐殖质层、粘化层和钙积层等三个基本层段组成。  

褐土剖面的上部具中性反应，下部碱性反应。钙积层富含石灰。表土腐殖质含量为3%许，有的可高达8%以上，腐殖质含量的剖面分布是由上向下渐减，显示一定程度草原土壤特征。  

# 3．利用和改良  

地中海地区的褐土处于亚热带夏干冬雨地区，水热条件不协调,这类土壤普遍用于种植油橄榄、葡萄和其他一些水果,也种植小麦、燕麦和大豆等农作物。在我国，由于褐土的表层质地较轻、结构良好，心土中有粘化层，而利于保水保肥，历来是我国重要的耕作土壤。有些褐土在长期的耕作、施用大量土粪等生产活动作用下，已被改造成为“楼土”。楼土有个厚达50～80厘米的覆盖熟化层，使得老耕层、原表土层和心土层均被埋藏于其下。  

# （四）红壤和黄壤  

# 1．地理分布和成土条件  

红、黄壤在亚洲东南部、非洲中部、北美东南部和南美北部等均有分布。在我国，这类土壤主要分布于江南丘陵及云贵高原的中亚热带地区。  

红、黄壤形成于中亚热带生物气候条件下。气候暖热、雨量充沛、无霜期长。自然植被主要是常绿阔叶林。  

2.形成特点和基本性状  

红、黄壤的形成，主要是富铝化和生物富集两个过程长期作用的结果。在暖湿的气候条件下，风化淋溶作用强烈，铝硅酸盐矿物遭到分解，硅酸与盐基大量淋失，铁、铝相对聚集,形成了富含铁、铝的红色土体.黄壤与红壤分布在同一生物气候带，富铝化程度相近或略低，但因其成土环境相对湿度较大，土壤经常保持潮湿，致使土体中的氧化铁水化，令土色变黄，尤以淀积层的黄色更是鲜明。黄壤中的氧化铁以针铁矿、褐铁矿和多水氧化铁为主，这同红壤有显著的差别。  

常绿阔叶林生长繁茂，每年可形成大量凋落物。在土壤微生物的积极参与下，其矿质化作用强烈，从而加速了生物与土壤之间养分物质循环。为此，土壤中难以积累大量的有机质，“静态的”营养物质含量似乎显得不高。  

红壤剖面以呈均匀的红色为其主要特征。在自然植被下，通常有一较明显的腐殖质层，呈暗棕色；剖面中部为粘重的土层，结持紧实；底部可见到杂色交织的斑纹。土体中常具铁结核等新生体，土壤呈酸性反应,粘粒部分硅铝率2.0～2.2,次生矿物主要有高岭石等。黄壤，土体一般呈浅黄色或蜡黄色，表土层有机质含量较高，淡黄灰色或暗褐色；心土层和底土层的质地粘重，有时可具潜育现象。  

# 3．利用和改良  

红、黄壤处于湿润亚热带地区,热量与光照充足，降水充沛，四季均可生长植物，且种类繁多，生产量大。宜发挥地区优势，发展农业生产，特别是发展亚热带经济作物。但要注意防止水土流失，维护生态平衡，并针对土壤酸性强、养分不足和质地粘重等问题，采取相应的改良措施。  

（五）砖红壤  

# 1．地理分布  

砖红壤广泛分布于热带雨林地区，高温多雨，年均温为25～28℃，年降水量大都在2000毫米以上。这类土壤主要分布于非洲中部、中美洲、南美北部、印度、印支半岛、印度尼西亚以及澳大利亚的北部。在我国，砖红壤主要分布于雷州半岛、海南岛和云南南部等地区。  

# 2.形成特点和基本性状  

砖红壤富铝化作用十分强烈，土体中原生矿物遭到彻底破坏，盐基物质强烈淋失，SiO，含量自剖面下部往上显著减少，而氧化铁、铝愈近上层聚积愈多。土层深厚，一般在3米以上，质地粘重，有明显的部面发育。在森林保存较好的情况下，地表有2一3厘米厚的枯枝落叶层；土壤表层是个暗红色或灰棕色的腐殖质层，具粒状或团粒状结构，疏松，多根系；其下为棕红色或赭红色的淀积层，多呈块状结构，结构面上有明显的暗色胶膜，具各种铁质新生体，如铁结核、铁磐等，还可见到铝的氧化物或氢氧化物积聚。土壤中原生矿物不多，次生矿物主要是高岭石，三水铝矿和赤铁矿。  

# 3.利用和改良  

砖红壤分布在湿润的热带地区，降水丰沛、热量充足，土壤化学风化强烈，生物循环快，农业生产潜力大，盛产橡胶、咖啡、可可、胡椒等热带经济作物和水稻，这里将是世界粮食和工业原料的最大供应区。这类土壤淋溶作用强，土壤中养分含量不高，酸性强，且易于水土流失，为此，在发展农业时，应建立合理轮作制，密切注意维护土壤养分物质的动态平衡，积极采取措施做好土水土保持，以确保土壤生产潜力的充分发挥。  

# （六）热带稀树草原土  

# 1．地理分布  

热带稀树草原土，又称红褐土或红棕壤，我国称之为燥红土。主要分布于非洲、澳大利亚、南美洲干旱炎热地区。如非洲撒哈拉大沙漠的南缘，构成了东西伸展、横贯非洲大陆的土壤带。在我  

国该类土壤主要分布在云南南部深切河谷地带和海南岛西南部。  

# 2.形成特点和基本性状  

：·热带稀树草原土乃是在热带干热气候条件下形成的一种特殊土壤。自然植被为热带稀树草原，常见仙人掌、霸王鞭等极耐旱植物，草本植物以旱生性为主。一般矿物风化程度较低，脱硅富铝作用不很明显。粘土矿物系以伊利石为主，其次是高岭石。土壤粘粒部分化学组成中，氧化铁在表层相对累积。由于淋溶作用相对较弱，旱季又受水分蒸发的“诱导”，盐基有表聚的趋势，盐基饱和度可达70～90%，pH值6.0～6.5.母质为石灰岩者，常显石灰反应，土体中可见到石灰结核。由于干湿季分明，雨季时植物旺盛生长，旱季时有机质分解缓慢，利于有机质的相对积累，表土层有机质含量可达3～4%。土壤剖面层次清楚，腐殖质层一般呈灰棕色，粒状或团粒状结构；淀积层呈红褐色，块状或棱块状结构；过渡层或母质层呈红、棕色或黄棕色。  

# 3．利用和改良  

该类土壤分布区，热量丰富、光照充足，主要问题在于干旱缺水。因此，在兴修水利，发展灌溉的同时,应注意植树造林,以缓和干旱。在此基础上，充分发挥其有利条件，有计划地开发利用，以期获得最佳的经济效益与生态效益。  

# （七）热带黑粘土（变性土）

# 三、草原土壤  

草原土壤分布在温带、暖温带以及热带的内陆地区，约占陆地总面积的13%。各大洲均有分布，其中以欧亚大陆分布最广。  

：·大多数草原土壤的形成，具有明显的生物累积过程和钙化过程。在草本植被下，土壤上层进行着程度不等的腐殖质的累积；土体中的碳酸盐普遍发生淋溶，并淀积在一定深度处，而易溶性盐类则几乎全部或大部淋失，粘粒和倍半氧化物则无明显的移动现象。  

大多数草原土壤的性状特征是：①土壤剖面分化清楚，具明显的“两层性”，即腐殖质层与钙积层；②士壤腐殖质含量，自表层向下逐渐减少，颜色也渐次变淡；③土壤一般显石灰反应，土壤中易溶性盐类含量较少，土壤代换量与盐基饱和度均较高，主要为钙离子所饱和，土壤溶液呈中性至碱性反应；4土体内二氧化硅和倍半氧化物均匀分布，一般无重新分配的现象。上述正是草原土壤区别于森林土壤、荒漠土壤以及其他类型土壤的最基本特征。至于草原土壤的不同土类之间的差别，则主要表现在腐殖质累积和钙化二个基本过程间的对比关系上。  

# (一）黑钙土(附黑土)  

# 1．黑钙土的地理分布和形成条件  

黑钙土在亚欧大陆分布相当广泛，在地理分布上表现了明显的地带性：自保加利亚北部、匈牙利东部、罗马利亚、前苏联乌克兰等地开始，经高加索北部、乌拉尔南部直达西伯利亚；再向东延伸，则因山地的干扰，而使远东的黑钙土成断续带状，一直伸展到我国的东北地区。北美洲的黑钙土，因受地形等因素的制约，呈南北向延伸的条带状，分布于美国中部。我国的黑钙土主要分布在黑龙江和吉林两省的西部，并伸展到燕山北麓和阴山山地的垂直带上。  

黑钙土是在温带大陆性气候、草原植被下发育的土壤。其气候特征是，夏热冬寒，年降水量约在300～500毫米之间。自然植被是以草原和草甸草原为主。成土母质主要是黄土或黄土状堆积物。  

# 2.黑钙土的形成特点和基本性状  

黑钙土具有明显的腐殖质累积过程和钙化过程。这里春夏增温伴以融雪，加上夏初降雨，土壤水分含量较多，使草类得以茂密生长，产生了大量的有机物质；晚夏干燥，冬季寒冻，土壤微生物活动受抑制，有机质难以分解；来年开春解冻，温度回升，微生物活动旺盛，并对有机质进行分解，但却因此时土壤湿度大，供氧不足，而只宜嫌气性分解，从而有利于胡敏酸类腐殖质在土壤中的累积。这些腐殖质和残留在土体中的钙盐结合，生成腐殖酸钙，这乃是水稳性结构的良好胶结剂。动物在这类土壤中活动颇为频繁，它们促使有机物质和矿质土粒充分混合，而利于深厚腐殖质层的形成。黑钙土的腐殖质层厚约30～40厘米，逐渐向下过渡，并有腐殖质呈舌状向心土层延伸现象。其钙化过程较为明显，碳酸盐沿剖面发生移动和淀积，心土层中碳酸盐呈斑块或结核状积聚，土层为浅灰棕或黄棕色。土质较肥沃，呈微碱性。  

# 3．利用和改良  

黑钙土自然肥力较高，生产潜力大，多已用于粮食生产。是世界小麦生产的主要基地，也是玉米、甜菜等作物的重要产区。但水分不足，乃是显而易见的限制因子。  

附：黑土  

分布于我国小兴安岭和长白山山前台地和平原地区的黑土，曾被称为退化黑钙土、变质黑钙土、淋溶黑钙土等。现研究表明，在形成条件上，黑土处于我国温带半湿润地区，年均温0.5～6.0℃，夏季温暖湿润，冬季漫长寒冷，年降水量450～650毫米，且季节分配不均，90%以上的降水集中于4～9月，冬季雪量少。季节冻层普遍。自然植被属草原化草甸类型，以杂类草群落为主，有“五花草塘”之称。植物种类多，无明显的优势种，生长繁茂，地上和地下部分的有机物质累积量很大。母质多为黄土状的冲积物和冲积-洪积物，质地多较粘重。这里的地下水埋深多在10～20米以下，对土壤的形成影响不大。但是，由于土壤质地粘重，底层透水不良，于土壤融冻水和降水集中的季节，在土体内部常可形成临时性的支持重力水层。这层支持重力水能够不断地向上层补给水分，保证草甸草被的繁荣生长，积累大量有机质,为土壤的高度腐殖化创造条件；同时还使土体下部造成嫌气环境，使铁及其他元素还原淋溶和淀积，在土壤剖面中出现了较多的铁质结核与锈斑、锈纹；有时，土体中尚可见到潜育层的发育。可见，黑土的形成主要表现为腐殖质的累积和矿物质的还原淋溶作用。同时，黑土还具有森林土壤的粘化、盐基淋失等的特点。该类土壤呈暗灰色，腐殖质层深厚，结构良好，疏松多孔;亚表层以下具黑色铁锰结核和二氧化硅白色粉末，以及锈斑、锈纹，质地较粘重；下层以轻粘土为主，无钙积层及石灰反应。pH值5.5～6.5，中性至微酸性反应。这些特点均与黑钙土有明显的差别。黑土的自然肥力高，多已垦为耕地，盛产麦类、大豆、高梁等。为保持与提高其肥力水平，仍需注意合理耕作、施肥和管理等环节。  

# （二）栗钙土  

1．地理分布和形成条件  

栗钙土和黑钙土相毗连，但更接近于内陆干旱地区。主要分布于亚欧大陆和北美大陆的温带干旱、半干旱草原地区。我国的栗钙土主要见于内蒙古高原南部，黑龙江、吉林两省的西部，大致呈东北-西南向的带状分布。这里，年均温3.3～5.5℃，年降水量350毫米许，蒸发强度大。自然植被属草原类型，由旱生多年生草类组成，以丛生禾草为主，其次是走茎和根茎草类。草原灌木和半灌木也占一定比重。  

# 2.成土特点和基本性状  

栗钙土形成的基本过程与黑钙土相似。但其植被较稀疏，入土有机质数量减少，而且，草原植被上的草类多于夏季因高温干燥而死亡，植物残体在炎热干燥的条件下进行好气分解，故有机质矿质化的速度大于腐殖质的积累速度。从而决定了栗钙土的腐殖质含量较低，腐殖质层厚度较薄，团粒结构的形成也较差。在干旱气候条件下，淋溶作用较弱，故栗钙土的钙化过程更为显著，碳酸盐淀积层层位比黑钙土高，并以斑块状、粉末状和核状的新生体形式出现，土体较紧实、颜色较淡，局部地区的下部土层尚有石膏积聚。全剖面呈微碱性至碱性反应，pH7～9,盐基呈饱和状态。  

# 3．利用和改良  

栗钙土的生产力次于黑钙土，虽含有相当数量的养分元素，但因降水不足,加上土壤结构较差，保水能力弱，难以保障生产。苏联的栗钙土大部栽培谷类作物;北美的乃是小麦重要产地；大洋洲、非洲和南美则以畜牧业为主。我国的栗钙土分布区主要为畜牧业生产基地，多属天然牧场。  

# （三）棕钙土  

# 1.地理分布和形成条件  

棕钙土主要分布在各大陆的温带荒漠边缘地带，其中以欧亚大陆荒漠草原地带的面积最大。我国的棕钙土系欧亚大陆棕钙土带的向东延伸部分。它主要见于内蒙古高原中西部、准噶尔盆地北部和天山、祁连山附近。  

棕钙土分布区属于温带较干旱的大陆性气候，年均温3.5～8.5℃，较栗钙土带高，降水量远小于蒸发量。自然植被包括荒漠化草原和草原化荒漠两个类型，均以蒿属和针茅属为主要成分。母质以残积物、洪积-冲积物和风成沙为主，也有部分的黄土。  

# 2.形成特点和基本性状  

在棕钙土的形成过程中，物理风化较强，化学风化与生物活动的作用较弱。土壤腐殖质累积强度不及栗钙土，土壤质地较粗并含有砾石，土壤剖面厚度一般不超过1米。土壤剖面构造特点是腐殖质层较薄，结构性差，有机质含量1.0～2.0%；钙积层多紧接于腐殖质层之下，层次厚而坚实，具石灰结核，底层可有石膏积聚。由于较干旱，淋溶作用弱，故碳酸钙、石膏和易溶性盐类的累积量和层位均高于栗钙土。全剖面呈碱性反应。  

# 3.利用和改良  

主要为天然牧场。发展农业全靠灌溉，且收获仍难保障。有效地防止风沙危害，解决水源，是发展农牧业生产不可缺少的条件。  

# （四）热带黑土  

热带黑土分布于热带草原区。在澳大利亚分布于昆士兰东部和新南威尔士的北部；在非洲断续分布于苏丹至南非之间的东部地区；在南美(称为红色湿草原土)则集中分布于拉普拉塔河流域。这类土壤腐殖质含量较高，土体中一般缺乏钙积层，并有一定的富铝化作用，而有别于温带草原的黑钙土等土类。  

# 四、荒漠土壤  

荒漠十壤亦称漠土，系漠境地区所发育的地带性土壤。  

# （一）漠土的地理分布和形成条件  

荒漠土壤广泛分布于温带和热带漠境地区。世界漠土约占大陆面积的10%，主要分布在如下六个地区：1非洲撒哈拉大荒漠、②澳洲大荒漠、③中亚大荒漠、④阿拉伯大荒漠、5南美大荒漠、6美国西南部大荒漠。其中，从撒哈拉大荒漠经阿拉伯大荒漠直到中亚大荒漠，几乎是一条相连的荒漠带。我国漠境地区，包括内蒙古、宁夏、甘肃和新疆等省（区）的一部分或大部分，其面积约占我国国土总面积的五分之一许。  

荒漠的生态条件极为严酷，气候极端干旱，年降水量少于250毫米，甚至只有数毫米，同时变率大，云量少，日照强烈，气温高而且较差大，蒸发强，蒸发量大于降水量数倍或数十倍，相对湿度小，多大风与尘暴。荒漠植被十分稀疏，甚至大面积棵露，植物种类有超旱生小半灌木、半灌木、灌木和小乔木等。荒漠的类型有石质、砾质、砂质和盐质之分。  

中纬度荒漠和热带荒漠，都具有荒漠的许多共同点，然而，两者毕竟位置有所不同，在气候方面，还是有差别的。中纬度荒漠冬季温度低，有少量降水，这是有别于热带荒漠的。而且中纬度荒漠冬寒夏热气候变化急剧，日较差大，年较差也大，天气的非周期性变化较为突出，寒潮、锋面、气旋和雷雨等剧烈的天气变化要比热带荒漠显著。  

# （二）荒漠土壤的形成特点  

漠土形成过程与草原土壤形成过程最主要的区别是：生物累积过程显著削弱，缺乏明显的腐殖质层；在干热气候的影响下，漠土中矿物质分解淋溶作用极微弱，形成了石灰表聚，以及石膏和可溶盐的相对聚积。荒漠土壤的共同特征为：①土体厚度薄，通常在50～70厘米之间，土壤组成与母质非常近似，表现为原始性，腐殖质含量低，通常在0.5%以下；②地表多砾石，表层可具孔状结皮，亚表层具有“粘化”和“铁质化”的红棕色紧实层；③普遍含有石膏和数量不等的易溶性盐。  

# （三）荒漠土壤的分类  

荒漠土壤的类型，以我国西北荒漠为例，分为灰漠土、灰棕漠土和棕漠土三个土类(表3-3)。  

灰漠土分布于温带荒漠向半荒漠的过渡地带；灰棕漠土是温带荒漠土壤；棕漠土则是暖温带荒漠土壤。这三类漠土虽有其共同点，但又有一定的差异：由灰漠土、灰棕漠土到棕漠土，其有机质含量渐次减少，胡敏酸与富里酸的比值逐渐变小；多孔结皮和鳞片状层的厚度与发育程度递减；石灰表聚和石膏、易溶盐累积递增，碱化作用表现为减弱的趋势。

# 五、盐成土壤  

盐成土壤也称盐渍土或盐碱土，包括盐土和碱土，以及各种盐化、碱化的土壤。它们主要分布在内陆干旱、半干旱地区或滨海地区.全世界盐渍土面积约占干旱地区总积的39%，我国盐渍土的分  

布范围也很大，约有五亿多亩。  

盐土进行着盐化过程，表层含有0.6～2%以上的易溶盐；碱土进行着碱化过程，交换钠占交换性阳离总量20%以上，结构性差，呈强碱性。  

# （一）盐土的形成过程  

气候干旱，蒸发强烈，地势低洼，含盐地下水离地表近等，是盐土形成的最有利条件。在降水量小于蒸发量的干旱、半干旱地区、土壤中盐分淋溶作用弱，水盐运行方向是从地下水或土壤深层向表土运行，随着水分蒸发逸散，盐分就遗留在土体的上部，使得表土层成为盐分的聚积层，从而导致盐土的形成。地形的高低起伏，也影响到地面和地下径流，土壤中的盐分势必发生随地形部位的再分配。显然，在排水不良或径流不畅的大、中地形(如内陆盆地、山间洼地、宽广平坦的平原地区等)的条件下,有利于积盐过程的进行。在微地形方面，其高处蒸发较快，盐分积聚也较多，往往在水平距离仅十多米，高差仅10厘米许的小地形上，盐分即可向高处运积而形成盐斑。除了气候与地形条件外，盐化作用还要求一定的水文地质条件,即只有在地下径流滞缓,地下水含盐量达到一定程度，并能上升到地面的情况下，土壤的积盐才能强烈地表现出来。再者，母质和生物条件也与盐化作用有关，毋质含盐多者，易形成盐土，盐生植物死亡分解也能给土壤表层聚积盐分。  

滨海地区盐土的盐分主要来自海水,通过潮汐直接给土壤增加盐分，将盐分补给地下水进而使土壤发生盐化。  

不合理的灌溉或渠系水分渗漏，可使地下水位抬高，在蒸发强烈的情况下也能引起土壤盐化,形成盐土。这是一种次生现象，称之为次生盐渍化。  

# （二）盐土的基本性状  

盐土的最主要特征是含有大量易溶性盐类，一般包括Na+、Ca²+、Mg²+等三种阳离子和 Cl-、SO²-、CO’-、HCO等四种阴离子所组成的各种盐类。一般说来,当土壤含易溶性盐达到0.1%时，一般植物的生长就已受妨害；达到0.2%时，影响较为显著；达到0.5%时，大部分植物不能生长；若超过1%时，则几乎所有植物均无法生长。  

盐土一般呈碱性反应。由于植被稀少,土壤有机质积累有限。除了表层聚盐较多或形成盐结皮外，剖面土层分化很不明显，土色多呈浅灰色-浅灰棕色。易溶性盐分在剖面中自上而下减少，呈正漏斗状分配；盐分组成，土壤上部以NaCl和Na2SO为主，下部多为 CaSO和 CaCO3。

# （四）盐渍土的改良利用  

盐渍土的形成过程，实质是各种可溶性盐分在土壤中重新分配、积累的过程。改良时，应采取以水利土壤改良为中心的综合治理措施，贯彻改良与利用相结合，因地、因时制宜的原则。对于碱土，还要考虑化学改良措施，施用钙盐（如石膏等）以钙离子置换土壤胶体上的钠离子，降低碱化度。实践证明，盐渍土经过不断改良，还是可以获得高产的。  

# 六、水成土壤  

水成土壤是指现代土壤形成过程中，长期或季节性水分过度湿润或水分饱和的土壤，主要有沼泽土、草甸土、白浆土等土类。  

水成土壤的主要成土过程包括潜育过程、育过程，以及腐殖质累积过程和泥炭化过程等。在水成土壤的各土类中，这些过程的组合和表现程度是各不相同的。水成土壤的共同特点是：土壤湿度大，有机质含量高，在土体的一定部位呈灰蓝色或灰白色，具锈斑和铁子等新生体。  

由于地区性因素或成土条件的差异，水成土壤的各土类及其特性是各不相同的。同时，水成土壤虽属隐域性土壤，但毕竟还是要打上地带性的烙印，故各种类型的水成土壤，它们的性质变异颇大。  

# （一）沼泽土  

# 1.地理分布和成土条件  

沼泽土广泛分布于地势低洼积水、地下水位很高的地段。其中分布最广的是在寒带森林苔原地带、寒温带针叶林带与温带森林草原地带之中。我国沼泽土主要分布在东北大、小兴安岭、长白山地和三江平原，同时在青藏高原、川西北的松潘草地也有较大面积的分布。  

沼泽土主要发育于高纬度地带，因为这里的气温低、蒸发量小、湿度大，土壤水分过多、长期受水分浸润，苔藓和其他喜湿性植物生长茂密，有利于沼泽土的发育。  

沼泽土总是与低洼的地形相联系。低洼积水而不易排于的地形条件，使地表径流汇集，长期积水，或地下水位抬升达地表，与地表积水共同作用，导致了土壤的沼泽化。再者，粘重的母质透水不良，也易于造成水分聚积，促使沼泽土的发育形成。  

# 2.形成过程和基本性状  

沼泽化过程包括有机质的泥炭化或腐殖化和矿物质的潜育化两个基本过程。  

在潮湿积水条件下，暖季沼泽植物生长茂密，形成大量的有机质，到了冬季，植物死亡，为土壤提供了大量的有机残体，这些有机残体在低温潮湿或积水的条件下，只能进行十分微弱的嫌气性分解作用，其分解过程十分缓慢，分解强度也低，而以粗有机质、半腐解有机质或腐殖质等形式累积于土体上部，形成一较深厚的泥炭层或腐殖质层。其土体下部，亦因水分过多，处于嫌气环境，铁被还原为亚铁。这些亚铁一部分下移进入地下水中，另一部分可沿毛管上升，在一定部位上聚积，并被氧化成氧化铁，这些氧化铁表现为斑点状、细条状或大块状结核的沼铁矿。同时，微生物的嫌气分解，还生成了大量的还原态物质，如H2、CH4、H2S和有机酸等，它们作用于土壤，可促使土壤中的铁还原为亚铁盐类，如蓝铁矿[Fe;（PO4)2·8H2O］,菱铁矿（FeCO3）,前者为白色,氧化后显浅蓝色，后者呈白色，氧化后显黄色，最后变成黄棕色。故潜育化作用的结果，于土体下部形成了一灰白色或蓝灰色的层次。总之，沼泽土的剖面由两个发生层组成：上部为腐殖质层或泥炭层，前者颜色较暗，常具粒状结构，后者呈棕褐色，松软，含水较多；下部为潜育层，呈灰蓝色或浅灰色，质地粘重。  

# 3.利用和改良  

沼泽土是个很有价值的自然资源，生产潜力很大。开发利用时，应根据土壤特性与所处的自然条件，全面规划，针对不同情况，采取不同措施，才能收到最佳的综合效益。沼泽土中的泥炭,在农业上,是一种优质的有机肥料资源。而且在工业、医疗卫生等方面，泥炭亦有其应用的价值。  

# （二）草甸土  

1．地理分布和形成条件  

草甸土是直接受地下水浸润，在草甸植被下发育而成的半水成土壤。它广泛分布于世界各大河泛滥地、冲积平原、三角洲以及滨海、滨湖等地势低平地区。我国草甸土主要分布在东北平原、华北平原、内蒙古及西北地区的河谷平原的沿河两岸等地。  

草甸土分布地区地势低平,地下水位较高，距地表一般多在1～3米之间。成土母质主要是新近沉积的冲积物或湖积物，具有明显的沉积层理。自然植被则以繁茂的草甸植被为主。  

# 2.形成过程和基本性状  

草甸土形成的草甸化过程，包括腐殖质化和育化两个基本过程。在草甸土形成过程中，随着地下水位的升降活动，导致土体中氧化、还原作用交替进行，铁锰氧化物随之迁移，并在局部聚积，从而在土壤剖面中出现了具有锈纹、锈斑和铁、锰结核的氧化还原层。其下常可见到还原作用较强的潜育层。草甸土的腐殖质积累过程较为明显，繁茂生长的草甸草本植物，为土壤提供了丰富的有机残体，在土壤湿度较大的条件下，进行嫌气分解，利于腐殖质的形成和积累。但草甸草本植物的根系主要集中于表层30厘米以内的土层中，之下则急剧减少。因此，草甸土的有机质含量也主要集中于表层，并向下锐减。这正与黑土腐殖质在剖面中积累较深的特点相比有着明显的差异。  

草甸土的剖面可分为两个基本层次，即腐殖质层和锈色斑纹层（潴育层）。腐殖质层，因其有机质含量的不同而呈暗灰色、灰色或棕灰色：锈色斑纹层，一般呈棕色或黄棕色，具明显的锈色斑纹与铁锰结核。再往下，尚可见到具少量锈斑、呈灰蓝色或浅灰色的潜育层。  

# 3.利用和改良  

草甸土的自然肥力水平较高，土层较厚，水分状况尚可，其适种作物广，产量也高。但在地势低平、土质粘重、土温低的地区，尤其是具有盐渍化特征的草甸上，则应采取水利与农业相结合的措施加以改良。  

# （三）白浆土  

# 1．地理分布与成土条件  

白浆土是一种滞水育性的半水成土壤。在我国主要分布于小兴安岭和长白山等山地的两侧，但以东侧为多。分布区的气候特点是冬季寒冷干燥、夏季温暖湿润，年均温一0.5～5℃，土壤表层冻结时间在150天左右，年降水量500～600毫米，夏秋雨量最多、冬季雨雪稀少。其所处地形主要是河谷阶地、山间盆地、谷地、山前台地和部分熔岩台地等。母质多属河湖相粘土质沉积物。地下水普遍埋藏很深，对土壤的形成几无影响，但是，由于母质粘紧不透水，故每当融冻或降水集中时节，土体上部经常滞水。植被多为喜湿性种类，主要是草甸和草甸-沼泽类型的草本植物。  

# 2.形成特点和主要性状  

白浆土的形成过程主要是特有的滞水育过程和较明显的腐殖质累积过程。这个滞水潴育过程是因土体上层周期性滞水而引起，滞水期间处于嫌气环境，一些变价元素(铁、锰等)被还原为游离低价态，大部分向下移动或随侧向水流水断淋失，一部分未淋失的，于滞水消失、氧化过程占优势时，又遭氧化并就地以铁、锰结核的形式固定下来。由于铁、锰的淋失，使土体褪色，形成了灰白色的亚表层，即所谓“白浆层”。表层土壤则在草甸草本植物的影响下，腐殖化过程有所发展，但较之黑土，则其程度相对较弱。  

白浆土剖面系由腐殖质层、白浆层、淀积层和母质层等构成。腐殖质层的有机质含量可达8一10%，结构较好；白浆层呈灰白色，紧实、具铁锰结核；淀积层呈暗褐色，粘重且紧实，向下逐渐过渡到母质层。  

# 3．利用和改良  

目前白浆土多已辟为农田。但它本身的植物营养元素总贮量不高，土质粘重，通透性能差，耕性不良，土壤缺乏保水、供水以及调节水分的能力。在开发利用中，应从增加营养物质和改善土壤水分物理性质两方面着手，并根据具体情况采取必要的排水防涝等措施，与此同时，也要注意蓄水防旱。  

# 七、岩成土壤  

岩成土壤是指在一定的环境条件下，由于某些母岩的性质对土壤的形成发育起了明显的延缓作用，使土壤仍较多地保持着母岩的某种特性，表现为与环境并不完全协调的一些土壤类型。如热带、亚热带地区的石灰土和紫色土；温带、暖温带干旱与半干旱地区的风沙土等。  

显然，岩成土壤的形成，仅仅是由于母岩的某些性质，使得土壤与环境条件的协调发展受到干扰，但应注意到，这些土壤在稳定发育的情况下，仍有可能在生物、气候条件的制约下，逐渐朝相应的显域性土壤方向过渡。  

# （一）石灰土  

石灰土是发育在石灰岩上的一种岩成土壤，热带、亚热带地区的石灰岩出露地方分布颇广，在我国以广西、云南和贵州境内分布较多。  

石灰土形成于热带、亚热带生物气候条件下，但石灰岩出露区，拥有源源不断的石灰岩新风化物和崩解碎片，而且土壤水中含有相当丰富的碳酸盐，这些物质进入土体，减缓了土壤中的盐基淋失，阻滞着脱硅富铝化作用的进行，形成为幼年性的石灰土。  

石灰土形成中，除了方解石碳酸盐类矿物受到不同程度的溶蚀外，其他矿物未曾受到强烈的化学风化。粘粒的硅铝率为2.4～3.6。按发育阶段的不同，石灰土有黑色石灰土、棕色石灰土和红色石灰土之分。黑色石灰土是富含碳酸钙和腐殖质的土壤，常具石灰假菌丝、白色粉末甚至石灰结核，呈中性至碱性反应，pH6.5～8.0，腐殖质含量较高，土色暗黑，表层多团粒或核状结构。棕色石灰土，碳酸盐分解淋溶较强，上层无石灰反应，pH6.0～7.5，化学分解增强，具胶膜，甚至有铁锰结核，土色暗灰棕。红色石灰土，碳酸盐淋溶作用有所加强，铁、铝、锰分解较强烈，发生一定的淋溶淀积，无石灰反应，呈微酸性，pH6.5左右，心土层为7.0～7.5，土色鲜红。  

# （二）紫色土  

紫色土是一种深受紫色岩石影响的土壤。在我国主要分布于亚热带地区，尤以四川盆地最为典型。  

形成紫色土的母岩为中新生代干热湖盆沉积的紫色砂、页岩，含钙质胶结物，岩性疏松，加之地形为丘状起伏，植被稀疏，土壤的侵蚀，堆积作用十分频繁，所以成土时间短暂，长期处于幼年阶段，土壤明显地继承母岩特性。  

紫色土呈紫红、紫红棕、紫暗棕、紫黑棕等颜色，土体上下层的颜色差别不大。土层浅薄，发生层分异不明显，但易于形成风化或半风化层。一般具石灰反应，但淋溶强烈者则无明显的石灰反应；通常pH7.5～8.5，淋溶强烈者为6.0～7.5，甚至有5.5～6.5的。由于受侵蚀严重，土壤中有机质的积累十分微弱。  

紫色土的母岩固结性差，易于风化成土，紫色页岩的自然肥力高，富含各种盐类及多种微量元素，酸碱适中，即使土层浅薄，但稍加耕锄便可栽种作物。目前，除丘陵顶部、陡坡岩坎外，多已开垦种植。在荒坡地或耕作管理不善的耕地，易造成水土流失。由于土层浅薄，底层难以透水，在排灌条件不好时，易受旱、涝的威胁。为此，应在精耕细作基础上，密切注意防止水土流失，采取措施加速土壤熟化。  

# （三）风沙土  

风沙土是在半荒漠、荒漠地区的风沙母质上形成的土壤。由于风沙的干扰很难进行正常的土壤发育，难以见到较完整和分化清晰的土壤剖面，始终表现出母质的特征。·  

风沙土，土质粗疏，不保水保肥，有机质含量很少，但含有较丰富的碳酸钙与各种盐类。风沙土尚可细分为流动风沙土、半固定风沙土和固定风沙土等三种。  

# 八、山地土壤  

山地土壤的特点是土层薄，石质较多，具明显的垂直分布特征。全球山地土壤约占陆地总面积的20%许,广泛分布于世界各地。山地草甸土、山地草原土、山地冰沼土、高山荒漠土和高山寒漠土等均有其自身特性。至于山地森林土与平地森林土相比较，也有许多不完全一致之处。  

# （一）山地森林土  

平地森林土如灰化土、棕壤、红壤和黄壤等在山地上均可出现。但在一些性状上则有若干差别，如山地灰化土的腐殖质含量一般略高；山地黄壤和山地红壤一般土层较薄、石砾含量多，富铝化程度相对低些。  

# （二）山地草甸土  

分布于高山、亚高山地带，物理风化作用占优势，母质多为岩屑。由于海拔高、气候寒冷、湿度大、风力强，有机质分解缓慢，土壤中累积了大量有机质。表层为草皮层，根系交织似毛毡，软韧而具弹性；腐殖质层呈灰棕或黑褐色，屑粒状、粒状或核状结构，向下则迅速过渡到母质或母岩。  

# （三）山地草原土  

分布于较为干燥的高山和亚高山地带。包括山地黑钙土和山  

地棕钙土等。其性状与平地相应土壤相当，但土层较薄，石砾较多，钙积层距地表较近。  

# （四）山地冰沼土  

分布于高山苔原带。温度一般比极地苔原低。生长有草类、灌木、真藓与地衣等不同植物。随着海拔高度和植被的差异,常发育成性状有别的山地冰沼土。  

# （五）高山荒漠土  

形成于高寒而干旱的严酷条件下，生长着以藜科和菊科为代表的高山荒漠植被，覆盖度很低。由于生长期极短，低温而极端干旱,使风化和成土过程均较弱。剖面发育较原始,土层浅薄,粗骨性强，细土物质少且具荒漠土壤的典型特征。表层有机质含量甚低，有多孔、易碎的薄结皮，并具有多角形裂缝。在薄结皮中夹有砾石或碎石，表面常有盐斑；薄结皮之下为薄片或片状层，在砾石背面具碳酸钙薄膜。全剖面呈碱性反应。  

# （六）高山寒漠土  

这是脱离冰川影响最晚，成土年龄最短的一类土壤。所在地形多为山地分水岭脊、古冰川斗和古冰平台，地面上岩石裸露或岩屑、冰砾石满布，活动的岩屑堆和融冻块石流广泛分布，只在局部地点有小片的粉砂土堆积，因而未能形成连片的土被。在高寒的条件下，只有一些冷生壳状地衣等着生于岩石或石砾的背风面。土层极浅薄，剖面分化很不明显。表层只含有少量有机质，土表有轻微上凸的融冻结壳，呈暗灰棕色，其下土层亦呈灰棕色，略显片状结构，通体大都是粗骨质，石砾含量甚高。  

山地土壤资源的利用，必需十分注意因地制宜，农、林、牧各有侧重，对现有森林要严加保护，积极做好荒山造林和封山育林，对山地天然牧场应防止过度放牧，提高山地草甸土与山地草原土的土壤肥力。有灌溉条件的山谷和缓坡，可辟为果园和农田，但应十分注意防治水土流失。  

# 九、水稻土  

# （一）地理分布和形成特点  

世界各大洲水稻土的分布主要集中在35°N～23°S之间，其中以亚洲所占的面积最大，约占世界水稻土总面积90%以上。但是世界许多国家并不把水稻土作为独立土类，土壤种植水稻后，仍沿用前身土壤的名称，并泛称植稻土壤。  

我国稻谷产量居世界首位，全国水稻土占耕地总面积五分之一以上。分布遍及全国,但主要分布区是秦岭-淮河一线以南,其中以长江中下游平原、珠江三角洲、潮汕平原、四川盆地和台湾西部平原最为集中。水稻土是我国十分重要的土壤资源。  

水稻土是人为耕作活动的产物。它系由各种显域性土壤、半水成与水成土壤等经过水耕熟化培育而成。在形成过程中，一方面经受着交替出现的氧化还原作用，使剖面发生明显的分化，另一方面在人为耕作、施肥、培土、灌溉等一系列措施影响下,进行着有机质的分解与合成，复盐基和盐基淋溶、以及粘粒的聚积和淋失等作用，使得原来土壤的特性发生深刻变化，从而形成了水稻土特有的理化性态和生物学特征。  

# （二）水稻土的剖面构造  

在水稻土的形成过程中，由于氧化还原的交替进行，土壤中物质的淋移、累积，以及反复的耕犁等人为影响，促使其剖面出现特殊的层次分化。它通常具有下列几个剖面发生层次：耕作层、犁底层、渗育层、淀积层、淀积-潜育层和潜育层等。①耕作层，是水稻土的表层，受耕作、施肥和灌溉的影响最大，淹水时，土粒分散为糊泥或泥浆状，结构体呈泥团状，排水落干后，土体龟裂为大大小小结构体，有屑粒状、碎块状、小块状和块状等，结构体表面具黄棕色或红棕色胶膜和锈纹、锈斑，并有少量铁锰结核和较多的未分解之植物残体；②犁底层，一般较紧实致密，多具扁平棱块状结构，沿裂隙和根底有黄棕色锈斑、纹；③渗育层，是由地面水下渗浸润淋洗影响而形成的，铁质受淋洗强烈，而显灰白色；④淀积层，多呈棱块状结构，结构面常被覆灰色胶膜，土体内多密布锈斑、锈点和铁锰结核；5淀积-潜育层，处于地下水变动的范围内，呈灰蓝色，有较多的锈斑、锈纹，结构不明显；潜育层，位于地下水位之下，终年积水，土色为蓝灰或绿灰色，粘韧，无结构。

# （三）水稻土的分类  

水稻土发育在各个生物气候带的不同耕作制下，既有共同性，又具地带性的烙印，故不同地区水稻土的形成过程和土壤性态是有所差别的（表3-4）。  

水分对水稻土的性态影响甚大，按水分状况，可将水稻土划分为如下几种类别：  

①地表水型水稻土。多属丘陵梯田，其排水良好，地下水位离地面很深。土体构型为耕作层-犁底层-底土层或耕作层-犁底  

层-淀积层-底土层。  

②良水型水稻土。多分布在河谷平原，其排水良好，地下水位离地面不深，种植水稻后，地面水(降水与灌溉水)与毛管上升水对土体共同发挥作用，土体分化明显，土体构型为耕作层-犁底层-淀积层-潜育层或耕作层-犁底层-淀积层-淀积潜育层-潜育层。  

③地下水型水稻土。多分布于水网密布的平原,其排水不良，地下水位高，甚至接近地表,水稻土呈耕作层-潜育层或耕作层-犁底层（-淀积潜育层)-潜育层的土壤剖面构造。  

此外，尚有侧渗水型水稻土和盐渍性水稻土,等等。  

# （四）培育高产稳产的水稻土  

水稻土是经过人们的生产劳动，把各种自然土壤或母质改造而成的人工土壤。由于环境条件和成土母质千差万别和土壤熟化程度的不同，形成了各种各样的水稻土。从生产角度来看，常分为高产田和低产田，这是就现状而言的。从实现我国的农业现代化的方向来看，在认识、掌握自然规律的基础上，从实际出发，因地制宜，发挥土壤生产潜力，使水稻土从低产变为高产，定向培育为能够旱涝保收、高产稳产、高度肥沃的水稻土，是完全可能的。
